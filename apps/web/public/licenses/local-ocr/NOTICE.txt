The application runs OCR locally. Original images and OCR text are not included
in the public OCR resource cache. Model source URLs and SHA-256 values are pinned
in scripts/ocr/models.lock.json in the application source distribution.

Local modification: the OpenCV 4.10.0 Emscripten JavaScript glue is adapted at
build time to replace createNamedFunction, makeDynCaller, craftInvokerFunction and
__emval_get_method_caller string-generated functions with ordinary closures.
See scripts/ocr/opencv-csp.mjs. This permits
the bundled OCR worker to run with a Content Security Policy that forbids
JavaScript unsafe-eval. The embedded OpenCV WASM is unchanged.
