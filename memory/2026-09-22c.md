### 修掉的真洞（值得单独记）

**`GET /api/admin/users/:username/preview` 会创建会话，而不是报告会话。**
上一批的注释写的是「reports an existing session」，代码调的却是 `requireLedgerPreview()`，
而它内部是 `registry.open()`——**一次普通页面加载就能解密用户账本**：没有最近登录校验、
不写审计原因、不写审计。POST 才有的那两道门全被绕过。
修法：注册表加 `find(username)`（只查不建），GET 改调它，没打开回 404 `PREVIEW_NOT_OPEN`。
测试 `reports an open preview without opening one` 断言：先 GET 得 404，POST 后再 GET 拿到同一个
id，且审计里 `ledger-preview-open` 只有 1 条。

**教训**：注释里的承诺和代码的实际行为是两件事，**改动路由时要把被调函数的副作用读一遍**。
这一批里我第二次犯「只看名字不看实现」——上一轮是把 `key-custody.ts` 的文件名当结论。

### 判断（本轮的关键设计决定）

- **写拦截放驱动层，不放 UI**。禁用按钮只是提示；`readOnlyDriver` 让 `run`/`exec`/`transaction`
  一律抛错，读原样放行。理由：漏改一个 `disabled` 是很容易的，而漏改驱动不会——所有调用者
  都过它。
- **拦截必须 `async` 抛**。第一版写的是同步 `throw`，`SqlDriver` 却承诺每个方法返回 Promise：
  用 `.catch()` 而不是 `await` 的调用者会拿到**未捕获异常**，把一次明确的拒绝变成整页崩溃。
  测试直接抓到了这个（`rejects.toBeInstanceOf` 失败）。
- **哪些界面要收窄，判据是「它描述的是谁的机器」**。设置（本机备份文件、存储占用）、同步
  （本机保存的连接）、Dashboard 的备份/自检提示、附件表的「本机/服务器副本」两列——这些放进
  预览会把**管理员自己的机器状态说成用户的**，「还没有本地备份」变成一句关于用户数据的假话。
  收窄方式：导航隐藏 + 路由重定向（两层都要，只隐藏挡不住深链和 sessionStorage 里存的旧 screen）。
- **附件只显示元数据**。阶段 5 没做，与其显示「按需下载」（暗示能取）不如写「预览不显示」。
- **预览不进 `sessionStorage` 的 screen 恢复逻辑**：那些键属于操作者自己的账本会话，
  预览消费掉它们，操作者回到自己账本时状态就丢了。

### 一个**先前就存在**的 bug（本轮顺带发现，未修）

`apps/web/dist` 的产物用相对资源路径，而 `serveWeb()` 对**两段路径**（`/admin/users/<id>`）
会把 `assets/index-*.js` 解析成 `/admin/users/assets/...` → 404 → **硬刷新白屏**。
我用 `/admin/users/<id>` 复现了（`[debug] after reload, has console shell: 0`，404 列表里是
`/admin/users/assets/*`）。所以预览地址我改成查询串 `…/preview?username=…`（与控制台其它
带状态的页面一致），**没有去动用户详情页**——那是独立的问题，不在本轮范围。

- **失败现场在 `tools/e2e/test-results/<test>/error-context.md`**，是 Playwright 的无障碍树快照
  （比截图好用得多，截图可能全白）。定位不到元素时先读它，能直接看到按钮文案与 dialog 名字。
- **`apply_patch`/多行 `edit_file` 在这个仓库仍不可靠**：一次多行替换把
  `it('…', async () => {` 和下一行粘成了一行。改完**立刻 `git diff --numstat` 或读回该行**验证。
- **`npm run release:check` 会扫源码里的字符串**：我在注释里写了
  `` `/admin/users?quota=over` ``，命中 `REMOVED_ADMIN_ROUTE` 正则（它匹配
  `/admin/(users|logs|…)` 后跟 `/`、`?` 或引号），门禁报「still exposes the removed /admin route」。
  **写注释提到旧路由时把路径拆开或改写**。
- **`loadBackup` 在 `useEffect` 里用但声明在后面**：`const` 有 TDZ，运行时才炸。tsc 不报。
  声明顺序要按依赖排。
- **渲染时机要等两份数据**：`summary`（POST 返回）和 `backup`（第二次请求）是两次请求，
  只等第一份就把 `undefined` 传给 `importLedger`，报出来的是「备份不是 JSON 对象」——
  描述的是症状，不是「还没加载完」。**先判 `!summary || !backup`**。
- **视觉自检很有用**：`image` 工具看截图发现「预览页套在管理后台页头里面」，
  两个 app 叠在一起（我在 `AdminShell` 里渲染，而不是在 `AdminApp` 里提前返回）。
