# 物品资产与配件记账

## 统一口径

“累计净投入”是物品资产页和物品报表的主金额：

> 累计净投入 = 累计支出 − 累计回款

累计支出包括整件购入、后续维修、升级、耗材及单独购买的配件；累计回款包括卖出配件和卖出整件物品收到的金额。金额按实际记录，不按折旧或当前市场价重估。页面中的“参考现值”只供查看，不参与累计净投入。

例如笔记本购入 5000 元，后来买内存花 2000 元，卖出原配内存收到 400 元：累计支出 7000 元，累计回款 400 元，累计净投入 6600 元。不需要给原配内存估价，也不需要给笔记本估现值。

“仅登记金额”只更新物品记录，不改变资金账户余额；“关联已有流水”复用已记的收支；“同时创建流水”才新建收支流水。物品金额与对应流水只建立一次关联。

## 配件与事件

| 操作 | 记录方式 | 金额归属 |
| --- | --- | --- |
| 购买整件物品 | 购入物品及其购入金额 | 计入整件物品的累计支出 |
| 购买可追踪配件 | 单独建立配件，填写实际购买金额并安装到整件物品 | 配件支出计入最近一次安装的整件物品 |
| 登记随整机购入的原配件 | 建立“原配件”，购买金额为 0 | 整机购入金额不拆分；以后卖出该配件的回款归原整机 |
| 对已有物品维修、升级或更换无需追踪的零件 | 记录维修／升级支出 | 计入该物品的累计支出 |
| 卖出无需单独追踪的配件 | 在原物品上记录“卖出配件”，写明名称和实际回款 | 从原物品累计支出中扣除回款，物品继续使用 |
| 卖出可追踪配件 | 在配件上记录“卖出该配件” | 回款归其成本所属物品，配件状态变为已售出，整件物品不变 |
| 拆下或转装可追踪配件 | 在配件上记录安装、拆下或转装 | 不产生新支出或新流水；单独购买配件的完整历史支出和回款归最近一次安装的物品。拆下后仍归最近安装的物品，直到转装 |
| 卖出整件物品 | 记录整件出售金额；对仍安装的配件选择“随整机出售”或先拆下 | 随售配件自动产生 0 元结束记录，整笔售价只归整件物品一次 |

旧“升级”记录可在时间线中转为可追踪配件。转换复用原升级事件及其资金流水，原金额转为配件购入金额，随后生成安装事件；不会再记一次支出。

对报废、清退和赠出，先拆下仍安装的可追踪配件。各物品的完整时间线保留购入、支出、安装、拆下、回款和状态事件。物品报表将已归属整件物品的配件金额并入该物品，避免汇总时重复计数。

当前数据库 schema 127 包含配件角色、原配件来源、安装目标、随整机出售关联，以及耗材的独立购买商户字段。当前代码不提供 schema 125 或 126 账本的原地升级；同一当前结构内的旧物品按整件物品处理，历史金额不会自动拆分或重新估值。

耗材购买金额在购买日计入累计支出；安装日期单独记录，未安装的备用耗材不计算剩余寿命或触发寿命提醒。同时创建流水时，购买商户复用为流水商户；关联已有流水时不修改原流水。
