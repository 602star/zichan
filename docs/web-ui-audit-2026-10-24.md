# Web 界面复审（2026-10-24）

## 范围与证据

这是 [2026-10-23 初审](web-ui-audit-2026-10-23.md)及五步整改后的技术复审。范围仍为 `apps/web`，包括个人账本、账号入口、共用控件与 `/admin`。对源码运行 Impeccable detector；对生产构建的登录页运行 390 × 844 和 1280 × 800 扫描，对管理入口运行 390 × 844 扫描；在浏览器中目视检查 390px 登录、注册和管理入口，并检查窄屏横向溢出。运行了生产构建、主题对比度与标签页键盘单元测试。

没有可用的账本及管理后台审查账号，因此登录后的界面尚未逐页目视操作。当前电脑也未检测到触摸屏或已连接的 Android/iOS 调试设备；图标选择器已按粗指针模式修正，但**真实触控设备上的误触与表单操作仍未验证**。分数只代表可取得的证据。

### 实现一致性判断

**通过。** 页面保留“温暖的个人分类账”的界面语言，三个主题及明暗模式共享语义 token；登录、账本与管理入口的主次层级一致。detector 对暖纸底色的 `cream-palette` 报警与已经确定的设计方向冲突，不作为缺陷。源码扫描中的三个 `side-tab` 报警位于管理日志、用户状态卡和资产转换标题，分别承载状态/分组信息；不以规则命中单独判为问题。其余少量色值、字号、圆角提示为建议项，需在后续设计系统维护时判断。

### 已完成的整改

1. **`$impeccable polish`**：调整六套主题的 `--fg-subtle`、浅色语义文字和赭石/鼠尾草主操作色；为输入占位文字指定主题辅助色；同步默认 CSS、favicon 与 `DESIGN.md`。
2. **`$impeccable harden`**：为设置、管理、交易对象、其他资料、资产转换和后台设置的六组标签页共用自动激活的键盘模型，并给当前面板建立 `tabpanel`、`aria-controls`、`aria-labelledby` 关联。
3. **`$impeccable adapt`**：粗指针下的图标网格和按钮至少 44 × 44px；在 390px 浏览器视口复核登录、注册、管理入口。
4. **`$impeccable optimize`**：根据网络请求确认手工 `ledger` 分块被登录页预载，移除该分块规则，让 Rollup 按实际加载边界拆分。生产构建不再有 543.32 kB 的 `ledger` 块或超过 500 kB 的块警告。
5. **`$impeccable polish` 与 `$impeccable audit`**：清理旧 favicon 色值及不准确的主题注释，复查窄屏呈现并重新运行源码与 URL detector。登录页两种视口仅剩既定暖纸底色提示；管理入口扫描无发现。

## 剩余发现与证据缺口

### P2 · 首次进入账本的加载成本尚未实测

- **位置/类别：** `apps/web` 生产包；性能。
- **证据：** 当前最大延迟加载 JS 块约 422.50 kB（压缩前），`UndoToast` 约 287.18 kB（压缩前）。已测登录页，但没有可用审查账号来测登录后首次载入、解析和交互时间。
- **影响：** 较慢设备可能在首次打开账本时仍有等待；目前不能断言是否影响实际任务。
- **建议命令：** `$impeccable optimize`。获得可用测试账号后，记录首次进入账本和首次进入重型页面的网络与主线程数据，再仅对确认的瓶颈继续拆分。

### P3 · 全局减少动态效果规则应按具体状态复核

- **位置/类别：** `apps/web/src/styles.css` 的 `prefers-reduced-motion`；可访问性。
- **证据：** 全局将动画/过渡设为 `0.01ms !important`。尚未观察到当前任务流的状态反馈被破坏，但以后增加承载状态的动画时可能一并消失。
- **影响：** 潜在状态变化可能缺少可感知的替代反馈。
- **建议命令：** `$impeccable harden`，在能操作各任务流时按状态提供静态反馈。

### 尚未完成的设备复核

- **真实触控：** 在手机或平板上以手指选择分类/交易对象图标，并完成登录、注册、关键记账表单；关注命中区、软键盘遮挡、页面滚动和提交反馈。浏览器窄屏截图不能替代这项测试。
- **登录后视觉/键盘：** 用测试账号进入账本与管理后台，实际按左右方向键、Home、End、Tab 操作六组标签页，并用屏幕阅读器检查面板名称。
- **设计文档侧车：** `apps/web/.impeccable/design.json` 仍记录旧的主题主色。按 Impeccable 的要求，本次设计任务不顺带修复生成物漂移；需要另行执行 `$impeccable document`/`doctor` 维护。
