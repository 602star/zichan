# Windows 桌面端本机验收记录

2026-10-10 至 2026-10-11，使用调试版 `zichan.exe` 的真实 WebView2 窗口、隔离的便携数据目录及本机测试同步服务器完成以下操作。所有账号、密码、账本与图片均为测试数据。

| 场景 | 实际检查 | 结果 |
|---|---|---|
| 两账本切换 | 同一账号在个人账本与受控共享账本之间往返切换，每次由桌面端重启，分别写入 12.34 与 56.78 元流水 | 各账本只显示自己的流水；两个 `ledger.sqlite` 及备份目录分别存在 |
| 同名附件隔离 | 两账本各上传名为 `same-name.png` 的有效 PNG，重启后预览 | 两张图片均可解码；加密对象文件的 SHA256 不同 |
| 服务端停服后继续记账 | 关闭测试服务器，在已打开的个人账本中写入 9.87 元，服务器恢复后同步 | 服务器个人账本提交数增加 |
| 冷启动离线访问 | 配置本设备离线密码，关闭服务器和桌面端，再离线启动桌面端 | 成功解锁原有加密账本，读取历史流水及图片，新增 4.56 元；服务器恢复后个人账本提交数由 5 增至 6 |
| 本地备份恢复 | 对含四笔流水和图片的个人账本创建手动加密备份，演练预检为 175 条实体、0 错误；复制完整测试数据目录，在隔离副本新增 0.33 元后精确恢复 | 0.33 元流水被移除，原四笔流水与 1×1 图片可读取；恢复前保护备份已生成 |

恢复验收发现原生备份列表只读取归档头，却把未知的预检结果显示成“0 条实体”。列表现改为“待校验”，演练后显示实际数量；恢复确认框使用当次已解密归档的预检结果。

此记录只证明一台 Windows 电脑上的真实桌面窗口与本机测试服务器行为。公网、家庭、办公室三台独立设备的网络故障、真实照片传输速度和长期运行仍需实机验收。
