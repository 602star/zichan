# 分类与交易对象图标

收支分类和交易对象的新增、编辑表单提供上传、预览、替换、恢复默认，以及 28 个内置图标选项。图标是可选项，新用户直接使用默认值。

## 显示规则

- 收支分类：自定义图标优先；内置分类按稳定分类 ID 分配图标。没有专属图标的二级分类继承父级图标，无法识别时回退为通用图标。
- 交易对象：自定义图标优先。平台按目录 ID（兼容名称和别名）匹配品牌图标，普通对象使用店铺图标，也可手选个人、公司等图标。
- 首批品牌：淘宝、美团、哔哩哔哩、网易云音乐、Steam、App Store。其他平台暂用通用图标，不拼凑未知来源的 Logo。
- 共享分类选择器的一级、二级、搜索结果和已选值，以及分类管理页、交易对象选择器和管理列表共用图标组件。保留文字和长名称换行，图标固定 18px；不增大记账弹窗。
- 图标仅辅助识别，使用 `aria-hidden`，不重复朗读名称。上传图片加载失败时回退为内置图标。

## 上传与同步

- 仅接受 PNG、JPEG、WebP，原文件最大 2 MiB。不加载外部图片 URL，不渲染上传的 SVG。
- 浏览器重新编码为 128×128 图片，等比完整放入画布，保留透明背景；不截掉长方形 Logo。不保存原图和原图元数据。
- 最终 data URL 最大 32,768 字符。小图直接写入 `Category.icon` / `Payee.icon`，随现有实体提交加密同步，并进入导出、恢复和审计；没有另一个需要下载的附件。
- 上传只改变表单草稿，点击保存才更新实体。处理期间禁止保存和关闭；无效上传保留之前的图标并提示错误。
- 恢复默认保存显式空串 `icon: ''`，不能用 `undefined` 替代：JSON 省略字段不能可靠表达跨设备清除。品牌默认图标会重新生效。
- schema 119：增加 `payees.icon`；117 和 118 均支持原地升级，保留原记录。图标随账本同步，使用这些字段的设备应升级到本版本。

## 资源与后续维护

统一图标使用 [Lucide](https://github.com/lucide-icons/lucide)；品牌使用 [Simple Icons](https://github.com/simple-icons/simple-icons)。采用静态具名导入，构建裁剪未使用的图标，无运行时图标 API 请求。许可证随前端发布在 `public/licenses/`：Lucide 的 ISC 与部分图标继承的 MIT 文本完整保留，Simple Icons 的 CC0 文本完整保留。品牌标识仅用作识别交易对象，仍须遵守各品牌规范。

新增显示入口应复用 `EntityIcon` 和结构化分类图标元数据，不再根据显示名称首字生成彩色块。新增平台映射前核对图标来源与品牌规范，缺失时保留回退。

回归覆盖上传格式限制、压缩后显示、刷新后的持久化、取消编辑、恢复默认、窄屏长名称、数据库升级、同步与导入恢复。
