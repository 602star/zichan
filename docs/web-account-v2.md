# 新版网页版账号入口

本说明取代旧版“浏览器本地模式兼容”设计。网页版只使用本站账号；桌面版仍可本地使用。

## 登录与注册

- `/app/` 在加载账本前验证账号。没有会话或会话失效时显示用户名/密码登录；有效 HttpOnly Cookie 可恢复会话，但仍需解锁本机加密缓存。
- 注册需确认密码；服务器关闭注册时不可注册，邀请模式需邀请码。账号创建成功但后续登录失败时回到登录状态，不重复创建账号。
- 忘记账号密码使用管理员审核的一次性重置码，不修改账本解密密码。
- 服务器尚未初始化时提示联系部署者；用户入口不提供创建管理员、管理标签、管理跳转或服务器启停面板。独立 `/admin/` 继续保留。
- 锁屏可“退出并切换账号”；进入账本后可在设置退出。退出撤销记账会话，不撤销独立管理会话。

## 存储与账号切换

Web 使用新的 `zichan.account.v2` 命名空间，按本站 Origin、serverId、accountId 隔离 IndexedDB、密钥封套、草稿、附件、备份、同步配置与界面偏好。旧的未分区浏览器账本和模式标记不读取、不迁移，也不自动删除。

一个文档生命周期只能绑定一个账号。切换账号需先退出并重载，避免异步写入落入另一账号缓存。不同账号的本机密码分别设置；同账号多标签仍通过独占 Web Lock 防止覆盖数据库。其他标签登录不同账号时，已打开账本的标签关闭存储并返回登录。

网页版同步页只展示当前账号、同步状态、账本加密与冲突处理；不提供新增服务器、编辑账号凭据或导入服务器目录。桌面版仍可配置多服务器连接。

## 离线边界

离线不允许新注册或首次登录。账号已绑定且未显式退出时，若应用页面能加载，断网可选择解锁该账号已有缓存。已经打开的账本可继续本地记录，网络恢复后同步。

当前没有新增 Service Worker 安装及应用壳缓存；完全断网下首次打开、关闭浏览器后冷启动或强制刷新能否加载页面，不作保证。浏览器主动清理网站数据仍会删除缓存，应保留服务器副本及浏览器外 `.zcbak`。

## 更新与验证

运行 `npm run build:server` 后，用项目启动脚本重启所需服务；本次开发没有代为重启用户服务，也没有清空用户实际数据库。

测试通过隔离服务器和浏览器资料执行。记账 E2E 每例使用独立服务器，避免共享账号、共享限流和 Windows 测试服务进程树清理问题。执行：`npm test`、`npm run lint`、`npm run typecheck`、`npm run test:e2e`、`npm run test:e2e:account`。

2026-09-09 最终验证：604 项单元/集成测试通过；Chrome、Edge 各 6 项账号专项通过（含换账号隔离与应用壳可加载条件下的离线重连）；Chrome 的 12 项新版记账流程通过；类型检查、Lint、Web 构建和发布一致性检查通过。桌面安装包未重新构建；Web ledger 分块仍有大于 500 kB 的体积提示。
