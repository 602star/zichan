# 新版网页版账号入口

> 当前账号保护采用[云端托管与私密模式](ledger-protection.md)：托管账号登录后自动解锁，私密账号使用恢复码。最新验收见[交付记录](release-readiness.md)。


本说明取代旧版“浏览器本地模式兼容”设计。网页版使用本站账号登录，登录后仍可连接多个同步服务器；桌面版仍可本地使用。

## 登录与注册

- `/app/` 在加载账本前验证账号。没有会话或会话失效时显示用户名/密码登录；有效 HttpOnly Cookie 可恢复会话；托管账本自动解锁缓存，私密账本使用恢复码或有效设备授权。
- 注册需确认密码；服务器关闭注册时不可注册，邀请模式需邀请码。账号创建成功但后续登录失败时回到登录状态，不重复创建账号。
- 忘记账号密码使用管理员审核的一次性重置码；托管账本随后可恢复，私密账本仍需恢复码。
- 服务器尚未初始化时提示联系部署者；用户入口不提供创建管理员、管理标签、管理跳转或服务器启停面板。独立 `/admin/` 继续保留。
- 锁屏可“退出并切换账号”；进入账本后可在设置退出。退出撤销记账会话，不撤销独立管理会话。

## 存储与账号切换

Web 使用新的 `zichan.account.v2` 命名空间，按本站 Origin、serverId、accountId 隔离 IndexedDB、密钥封套、草稿、附件、备份、同步配置与界面偏好。旧的未分区浏览器账本和模式标记不读取、不迁移，也不自动删除。

一个文档生命周期只能绑定一个账号。切换账号需先退出并重载，避免异步写入落入另一账号缓存。离线密码与设备授权按账号隔离；同账号多标签仍通过独占 Web Lock 防止覆盖数据库。其他标签登录不同账号时，已打开账本的标签关闭存储并返回登录。

网页版和桌面版均支持多服务器同步连接。入口为“设置 → 管理同步服务器”或“同步”；轻量记账默认隐藏同步菜单，但设置入口始终可用。支持新增、编辑、删除附加连接、独立登录、启停同步、连接链接/二维码及加密共享服务器目录。用户同步连接不等于服务器管理，不恢复管理员初始化、用户管理或启停服务面板。

本站连接负责当前账号登录及缓存归属，不能在同步页删除、停用、更改地址或用户名；切换账号须退出后重新登录。附加服务器可有不同用户名和密码。重新登录保留当前账号的连接列表、稳定连接 ID 与自动同步偏好，不再重置成单台服务器。

同一服务器可有本机、内网和公网地址，地址合并前校验 serverId/公钥；不同服务器分别认证后同步当前账本。发现不同账本仍走原有冲突/加入流程，不因新增服务器就自动覆盖或合并无关账本。

附加连接在 Web 中使用独立令牌会话，不覆盖本站 HttpOnly Cookie。令牌保存在当前账号分区的 sessionStorage，刷新可恢复，关闭标签页后通常需重新登录；账号密码不写入存储。它不像 HttpOnly Cookie 能隔离同源 JavaScript，部署时应维持 CSP、HTTPS 和依赖安全。桌面版继续使用 Stronghold。退出时先清理本地凭据，再尝试撤销各已登录服务器会话；断网、访问令牌过期或身份变化时标记撤销未确认。

本机可配置 `http://127.0.0.1:8787`；公网必须可信 HTTPS；局域网建议可信 HTTPS。HTTPS 页面访问 HTTP 内网地址仍可能受浏览器混合内容或本地网络访问策略限制，客户端不会绕过浏览器安全限制。可使用目标服务器自带 Web 入口或桌面版。地址默认只保存在当前设备；公网共享地址进入账本加密目录，其他设备仍须自行登录。

## 离线边界

离线不允许新注册或首次登录。账号已绑定且未显式退出时，若应用页面能加载，断网、请求超时或服务器 5xx 均可选择解锁该账号已有缓存，不依赖浏览器的联网标志。使用已设置的独立离线密码或有效的记住设备授权。401/403、账号切换、服务器身份变化、无效 JSON 等验证失败不会开放离线入口，并显示具体原因。已经打开的账本可继续本地记录，恢复服务后可刷新验证账号或按已有同步调度继续同步。

生产 Web 使用完整版本的 Service Worker 静态资源缓存，安装完成后支持已授权账号离线冷启动；首次访问和首次登录仍需联网。更新等待全部旧页面关闭，详见 [离线应用资源](offline-app.md)。浏览器主动清理网站数据仍会删除缓存，应保留服务器副本及浏览器外 `.zcbak`。

- 注册要求确认密码；切换连接清空未提交的密码和邀请码。注册已成功但自动登录失败时明确提示直接登录，避免重复注册。
- 账号请求及同步 JSON 请求有 15 秒默认超时（连接测试 5 秒），覆盖响应正文读取，支持取消；管理登录/恢复也使用相同保护。写操作超时提示结果未确认，不自动重放请求。备用地址仍按既有身份校验规则尝试。
- 共享目录读取失败、JSON 损坏、未知版本或无效条目时暂停自动写回，保留原始内容并提供重新读取入口。保存前再次验证已有目录，不把读取失败当空目录覆盖。
- 删除附加连接先确认，再校验目标身份并尝试撤销会话。撤销未确认时保留连接，用户可取消，或再次明确选择“仅删除本机连接”；提示远端会话可能仍有效。删除不删除本机账本、远端账号或远端账本，本站主连接仍不可删除。
