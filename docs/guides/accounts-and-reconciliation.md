# 资金账户与默认收支

电脑端从侧栏“账户”进入；手机可从“资产 → 账户 → 账户管理与默认收支”进入同一工作区。两端共用账户数据、默认用途、余额与对账逻辑，继续使用纸、墨、朱色控件。

## 默认支出与收入

页面顶部可分别选择默认支出账户、默认收入账户，然后点击“保存默认设置”。新记账表单未手动选择账户时使用对应默认值；两个方向可以选同一个资金账户。只有启用的账户可作默认用途。

默认设置只影响之后的新收支，不会迁移已有记录、改变其余额归属。退款仍按原消费的账户归属处理。新增或编辑账户时，也可勾选“今后支出／收入默认使用这个账户”。取消当前默认用途后改用其他可用账户；若该方向已使用另一个账户，不会被取消操作覆盖。

新账本预建“默认支出账户”“默认收入账户”，类型为“其他”。它们和自行添加的资金账户一样，直接列在同一清单中，可收款、付款、转账、改名和设置默认用途；任何启用账户都可同时用于支出和收入，不再按名字限制方向。不细分银行卡或钱包的人可一直用这些账户记账。仅这两个系统预建账户不再提供新建对账，其已有对账仍可查看和撤销；自行添加的“其他”账户，以及设为默认收支的银行卡、钱包，继续提供对账。识别依据是系统预建身份，不是名称或当前默认用途，改名后规则不变。

旧版默认账户保留原 ID、名称和流水，转为普通账户；原先系统预建的钱包类型改为“其他”，用户已改成信用卡等类型的资料继续保留。从此这些账户的历史收支也计入原币余额及资产汇总，因此汇总可能与旧版不同。这次转换不新增交易、不改写已有流水，也不补造期初余额。未设余额起点时，从已有记录累计余额；只有支出没有收入或期初余额时，余额可以为负数。需要逐笔与真实银行或钱包账单核对时，请在对应的自建资金账户中使用“核对账单”；系统预建账户只记录收支与余额。

## 清单与账户工作区

资金账户清单可搜索名称、平台，并按启用或停用筛选；零余额账户也保留。余额按原币分别显示，不把人民币、美元等数量直接相加。默认支出、默认收入及停用状态均有文字标记。

点击账户后定位到通栏工作区，通过三个页签处理任务：

- **账户流水：** 查看收支、转账和资产转换的分录及逐笔余额，可按日期和币种筛选，每次读取 100 笔并继续加载。账户期间独立于日常收支的查询条件，初次查看为全部时间。切换账户或币种后，旧查询结果不会出现在新账户标题下。
- **对账记录：** 仅显示当前账户在所选期间的记录。点击“核对账单”复用现有余额核对、勾选流水及差额处理；资产转换参与余额计算，不转为日常收入或支出。
- **账户资料：** 查看类型、平台、余额起点、起始余额及账单／还款日期。普通编辑可改资料和默认用途，不改原余额起点；要调整起点，使用“从更早日期核算”的独立预览和核对流程。

余额或流水读取失败时显示问题及“重新读取账户”，不会把失败当成零余额。余额起点不算收入；添加账户后，以前的收支仍保留原归属，需要时另用“整理以前的记录”。

桌面新增／编辑、核对账单分别独占主内容区；同一时间只打开一个账户任务，不能再同时展开对账和编辑。手机使用纸面表单及共用选择面板。关闭未保存的账户编辑或对账时，可继续处理或放弃输入；与其他窗口发生默认设置变更冲突时，重新打开账户后再编辑，避免覆盖新设置。Android 系统键盘、返回、文件与前后台切换仍按[真机清单](mobile-ledger.md)另行验收。

## 核对账单怎么算

对账是在已有流水与银行／钱包账单之间逐笔确认，按一个账户、一种币种、一个截止日分别处理。它不会把已记录的消费再扣一次，也不会自动把余额改成输入的数字。

1. **填写实际余额。** 输入银行或钱包在所选截止日的账单期末余额；零余额也要明确填写 `0`。信用卡账单欠款填负数，不填信用额度或可用额度。
2. **勾选账单上的流水。** 收入、退款为加，支出为减，转账按当前账户的转入／转出方向计算。“勾选当前列表”只增加当前搜索结果中的勾选，不会把隐藏结果一起选上。勾选“待核实”流水意味着已在外部账单中确认，完成后将改为已核实。
3. **看余额与差额。** 页面分别显示余额基准、勾选流水净额、本次核对余额、差额；买卖及换汇的实扣／到账单独显示自动计入的净额，不能重复作为收支勾选。

计算为：**余额基准 + 勾选流水净额 + 本期资产转换净额 = 本次核对余额**；**账单期末余额 − 本次核对余额 = 差额**。

余额基准优先使用该账户、该币种上次已完成的对账余额；首次核对使用账户起始余额。没有设置该币种起始余额时从 `0` 开始，并在页面明确提示。已经包含在起始余额中的流水、已经核对的流水不重复计入；截止日之后的流水留到后续。

例如起始余额 1,000 元，银行账单已显示一笔 100 元支出，实际余额 900 元：勾选这笔流水后计算为 `1000 - 100 = 900`，差额为零，可以完成。若账本另有 50 元尚未出现在银行账单上的支出，留着不勾选即可；它仍计入账本余额，所以账本余额可以是 850 元，本次已核对余额是 900 元。未勾选记录不删除，下次出现于账单时继续核对。

差额不为零时，先检查漏记、重复记录、币种、日期和勾选范围；需要补记可关闭当前核对后处理。确认确属余额差额时，再展开“用余额调整处理”，勾选确认并点击“创建调整并完成对账”。这才会新增一笔余额调整：正差额增加余额，负差额减少余额，不算日常收入或支出。修改金额、日期、币种、勾选内容后，原确认失效；保存时若差额已变化也会要求重新核对。

普通“完成对账”只保存对账结果与流水确认状态，不新增消费或收入。已完成的流水受保护，需更正时按同一账户、同一币种从最新一期开始撤销；本期产生的余额调整会同时作废。新一期截止日必须晚于最近一期，同一天要重做应先撤销原对账。
