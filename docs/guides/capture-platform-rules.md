# 平台订单与发票提取规则

解析结构为本机 OCR → 通用字段解析 → 命中特化规则补充证据 → 人工核对。规则不依赖固定屏幕坐标，不按最大数字猜付款金额。`apps/web/src/order-capture/rules.ts` 注册规则，`parser.ts` 负责标签与邻近文本关联、候选去重、冲突及状态判断；增加平台不需要复制解析器。

## 当前标签覆盖

以下是已经编写并以合成 OCR 文本验证的规则范围，不表示各平台全部版本、页面和截图质量均经过实测。没有品牌文字时，明确“实付款”“付款时间”等字段仍由通用规则处理；识别不清时允许手改，不编造缺失字段。

| 平台／页面 | 特化金额标签示例 | 其他处理 |
| --- | --- | --- |
| 淘宝／天猫 | 买家实付 | 保留通用订单号、付款时间 |
| 京东 | 实际支付、已支付金额 | 应付总额不当作实付 |
| 拼多多 | 实付共计、实际支付 | 拼单文字可提供平台证据 |
| 抖音、快手小店 | 支付合计、实际支付 | 抖音主订单号可作订单候选 |
| 闲鱼 | 我实付款、买家实付 | 宝贝名称可作描述候选 |
| 美团 | 实付合计、实际支付 | 餐厅名称、餐品名称 |
| 饿了么 | 在线支付金额、实际支付 | 餐厅名称 |
| 唯品会、苏宁易购 | 订单实付、已支付金额 | 保留通用字段 |
| 1688、小红书 | 买家实付、实付合计 | 保留通用字段 |
| 微信、支付宝账单详情 | 支出金额等明确标签；成功支付账单中的独立负号金额 | 交易号与商户订单号分开，只有后者填订单号；结合账单字段结构识别，不强制依赖品牌标志 |

负号金额仅在有足够支付账单证据时转换成支出金额。收入、转账、充值、提现页面不通过负号推断购物支出。不根据创建时间／下单时间推断付款时间。原价、优惠、运费与合计不替代明确实付；同级多个不同实付仍标为歧义，需人工选择。未付、关闭、退款等状态继续阻止直接回填。

## 国内发票

目前适配带明确票头的数电发票、增值税普通／专用发票和电子普通／专用发票。普通订单中的“发票信息”菜单不会触发发票模式。

- `价税合计`（含小写金额）作为金额候选，不取不含税金额或单独税额，不从大写金额猜数值。
- `发票号码`、`发票代码`、`开票日期`使用独立流水字段。开票日期不替代交易日期；不会把发票号填进订单号。字段可手改、复制、看原图依据，随流水同步、审计、备份与恢复。
- 发票号候选接受 8 位或 20 位数字，代码接受 10 位或 12 位，保留前导零；数电票缺少代码时留空，不补造。依据：[税务总局数电发票公告](https://fgk.chinatax.gov.cn/zcfgk/c100012/c5236067/content.html)、[电子普通发票代码及号码规则](https://fgk.chinatax.gov.cn/zcfgk/c100012/c5194596/content.html)。这些长度校验不能查验发票真伪。
- 商家优先取销售方名称，支持明确销售方信息区中的名称。购买方、税号、开户行、银行账号、校验码、开票人等不自动进入商家、描述或备注，默认建议遮盖对应敏感区域。
- 发票不证明付款，核对页常显提示；红字、作废、红冲不当作普通已付款购物。不同发票的金额／号码冲突保留歧义，不自动汇总、多笔入账或静默合并。暂不提供抵税计算、真伪查验、海外票号或 OFD／XML 解析。

## PDF 与图像

图片及 PDF 均从对应附件旁直接提取。PDF 使用已有本机 PDF.js 资源，先把全部页转换为连续图像，再走同一 OCR 与隐私流程，不调用第三方服务。

PDF 限制为最多 6 页、原文件及转换 PNG 各不超过 20 MiB、总像素不超过 2400 万、合并高度不超过 16000 像素。超限要求拆分，损坏／加密文件提示处理原因，原附件保留；取消读取会终止转换。脱敏后用一张包含全部页的 PNG 替换该 PDF，移除原 PDF 的隐藏文本、元数据等结构；“保留原始 PDF”则保留原文件，不进行打码。不会悄悄只处理第一页或删掉后续页。

## 验证与继续适配

`apps/web/test/order-platforms.test.ts` 保存字段、状态、分框位置与反例，不存私人截图。`tools/e2e/tests/invoice-capture.spec.mjs` 用合成中文图片与多页 PDF 运行真实模型，核验字段、独立日期、全部页遮盖、下载格式、元数据清除、损坏及页数限制。

后续按经过本机脱敏的具体样例补平台变体：记录页面类型、期望字段、遮盖及候选冲突，加入对应规则和反例，再通过真实 OCR 回归。OCR 文字与规则解析分别验证，避免把排版／字体识别失败误当成字段规则缺失。现阶段不承诺低清、裁切、旋转、盖章遮挡或所有平台版本的识别率。
