# 电脑端账本工作台

电脑端面向查流水、对账和连续录入。沿用“大福帳”的文献纸、墨线与朱色操作，分类选择、日期、附件、表单校验和草稿与移动端共用。

## 导航与页面

- 日常：工作台、流水、账户与计划。计划中分别管理预算、账单和定投，不混算消费与投资。
- 资产与分析：资产转换、物品资产、游戏赛季及报表。模块显隐继续遵守侧栏偏好；不再额外提供重复的“资产”聚合入口。
- 账本工具：资料管理、操作历史、我的账号和设置。资料、设置、账号采用局部目录，一次处理一个任务。

宽侧栏可收起；平板窗口保留紧凑导航。电脑端在工作台查看资产概况，账户、转换与物品分别进入对应任务。手机继续使用底部五项导航，保留“资产”聚合页。

## 查流水与连续录入

流水占用完整正文宽度。点击记录或“详情”在该记录下面展开原币金额、账户、状态及附加信息；点击“编辑流水”再进入完整业务表单。日期之间用墨线分隔，显示每日支出小计；小计和范围摘要使用完整查询聚合，包含尚未加载到屏幕的记录。

“记账”在桌面列表上方打开录入区。新增提供“保存”和“保存并继续”，Ctrl／Cmd+Enter 执行保存并继续。成功后清空金额和描述，焦点返回金额；“沿用常用字段”决定是否保留日期、时间、账户、币种、类型和分类。附件、退款关联及其他本笔信息不会带入下一笔。保存失败保留输入并定位错误。

搜索保持可见，额外条件点击“筛选”展开。当前范围摘要与日期选择一致，并沿用退款归属、转账排除和缺价规则。编辑后保留筛选；同一账本会话中切换页面再回来，也保留查询与账户选择。临时查询不跨重新加载保存；需要长期保存时使用已有“保存视图”。

编辑和连续转换在主内容区展开，手机仍使用原有纸面弹层。未保存时切换页面会先显示草稿保护；可继续编辑，或保留草稿并关闭后再选择目标页面。Esc 关闭当前编辑层，嵌套的选择和确认仍由各自弹层处理。

## 账户、计划与资产

账户页保留逐币种余额、余额起点、账户流水与对账记录。核对账单在流水上方展开，实际余额、差额及确认动作使用既有对账逻辑；买卖和换汇影响账户分录，不作为日常收支混算。

定投计划可查看、编辑并进入“登记本次买入”，实际成交在转换表单中核对。资产转换在桌面默认显示记录时间线，持仓概览仍可切换查看；复杂新增／编辑进入完整主区，保留手续费、连续步骤、保留数量及成本依据。

资产总览分别展示金融资产估值与原币数量，缺价部分保留数量并明确提示；资金账户不与已含账户余额的持仓重复相加。物品参考残值及使用成本在物品页查看。物品桌面清单便于比较，进入详情后按概况、使用和事件组织，继续使用原有指标单位和生命周期控件。

游戏记录先查看，再明确编辑；游戏币数量、原币结算和缺价提示各自列出。操作历史采用完整列表／详情往返，差异与撤销继续使用审计记录。报表在宽窗口并排放置期间走势和构成，保留统一期间、下钻与精确明细。

## 验收边界

浏览器回归覆盖桌面与手机共用页面；Android 系统键盘、返回键、权限、文件和前后台切换仍需另做真机验收，见[移动端页面与操作](mobile-ledger.md)。
