# 电脑端账本工作台

电脑端面向查流水、对账和连续录入。沿用“大福帳”的文献纸、墨线与朱色操作，分类选择、日期、附件、表单校验和草稿与移动端共用。

## 导航与页面

- 日常：工作台、流水、账户、账单与还款、计划。账单和还款可独立使用，无需先创建资金账户；计划中管理预算与定投，不混算消费与投资。
- 资产与分析：资产转换、物品资产、游戏赛季及报表。模块显隐继续遵守侧栏偏好；不再额外提供重复的“资产”聚合入口。
- 账本工具：资料管理、操作历史、我的账号和设置。资料、设置、账号采用局部目录，一次处理一个任务。

宽侧栏可收起；平板窗口保留紧凑导航。电脑端在工作台查看资产概况，账户、转换与物品分别进入对应任务。手机继续使用底部五项导航，保留“资产”聚合页。

## 工作台与到期提醒

首页先用一张“账本概况”面板展示净资产和所选期间的收入、支出、结余，避免资产快照与收益指标重复。下方并排放置“账单与还款”和“最近流水”，均使用统一 Card，内部通过墨线分行。最近流水保留原币、日期、账户及直接打开对应记录的动作。投资与使用成本、其他待办、资产配置及期间动态随后展示。

账单提醒覆盖未来 30 天和仍需补记的计划，每个定期计划显示最早未处理期次，生成或跳过后前进至下期。自动记账失败单独提示；计划日已过只表示尚未登记，不能据此认定尚未付款。支持按定期账单／信用卡筛选及展开其余项目。

信用卡账户可按设置的账单日、还款日补充日期提醒，月底自动取有效的最后一天；不从账户余额推断每期应还金额或还清状态。无需关联账户的房租、订阅、分期及还款计划，从“新增账单／管理全部计划”维护，可仅标记已处理而不生成收支，详见[账单与还款](bills-and-repayments.md)。提醒以账本时区的今天为准，独立于统计期间，跨日或回到应用时刷新。

手机在收支优先模式下先显示最近流水，提醒默认显示两项并可展开；资产优先模式先展示提醒。负余额保留负号，存在负余额时资产配置仅列净额、不计算配置占比，避免把负债画成正资产。

## 查流水与连续录入

流水占用完整正文宽度。点击记录或“详情”在该记录下面展开原币金额、账户、状态及附加信息；点击“编辑流水”再进入完整业务表单。日期之间用墨线分隔，显示每日支出小计；小计和范围摘要使用完整查询聚合，包含尚未加载到屏幕的记录。

“记账”在桌面打开居中纸面弹窗，新增、编辑和退款使用相同的弹窗基础；不挤占列表上方。新增提供“保存”和“保存并继续”，Ctrl／Cmd+Enter 执行保存并继续。成功后清空金额和描述，焦点返回金额；“沿用常用字段”决定是否保留日期、时间、账户、币种、类型和分类。附件、退款关联及其他本笔信息不会带入下一笔。保存失败保留输入并定位错误。

搜索保持可见，额外条件点击“筛选”展开。当前范围摘要与日期选择一致，并沿用退款归属、转账排除和缺价规则。编辑后保留筛选；同一账本会话中切换页面再回来，也保留查询与账户选择。桌面分类列按全部内置分类的完整父子路径预留宽度：最长中文路径“金融税费 / 外币兑换手续费”在 16px 文楷下约宽 193px，预留 200px 文字空间和两侧共 16px 留白，并随字号同步放大。768–1023px 时将时间、账户移至摘要下方，保留完整分类列；手机与更长的自定义分类按空间自然换行，完整名称直接可读。退款状态、累计冲减及净支出放在金额列，摘要保留描述；全额退款保留原支出金额，避免与作废混淆。临时查询不跨重新加载保存；需要长期保存时使用已有“保存视图”。

流水编辑及退款使用弹窗；账户编辑和连续转换仍在桌面主区处理，手机继续使用纸面弹层。未保存退出会先显示草稿保护；可继续编辑，或保留草稿并关闭后再选择目标页面。Esc 关闭当前编辑层，嵌套的选择和确认仍由各自弹层处理。

## 记录与查看退款

在原支出的详情或手机操作面板中选择“记录退款”，表单预填剩余可退金额；改小即为部分退款。同币种时只填写实际到账的“金额”，不另填冲减额；跨币种时分别填写到账币种与金额、按原支出币种计算的冲减额。退款按既有归属设置冲减支出，不重复当作普通收入。

原支出行的金额列保留原消费，下面显示累计退款冲减和净支出。全额退回时净支出为零，原消费仍是真实历史记录，不划掉成作废。点击金额列的退款状态可查看、编辑、作废退款或继续登记剩余部分；累计冲减不能超过原消费，编辑时不把当前退款重复扣入可退额度。

仅筛选退款或原消费不在当前页时，编辑仍按需读取原单、拆分分配、附件及退款记录，不要求先清除筛选。超额时在实际填写的金额字段提示并保留输入；修改及作废后，原行状态、净支出与期间统计重新计算。列表中的净支出按原消费币种展示累计结果，期间汇总仍按退款归属设置计算；跨币种实际到账在退款记录中查看。

## 账户、计划与资产

账户页按默认收支设置、资金账户清单、通栏账户工作区组织。分别选择默认支出和收入，只影响之后的新记账；系统预建的默认账户类型为“其他”，与自行添加的账户一起列示、参与余额和转账；仅这两个系统预建账户取消新建对账，自行创建的账户即使被设为默认收支也保留对账。默认只是用途，不是另一类账户。清单可比较原币余额、默认用途、状态及余额起点，保留零余额账户。点击账户后定位到工作区，按账户流水、对账记录、账户资料处理任务；账户期间独立于日常收支查询，对账记录仅列当前账户。新增／编辑在主区展开，关闭未保存修改前提供保护。详见[资金账户与默认收支](accounts-and-reconciliation.md)。

核对账单与编辑账户分别独占主区，账户任务互斥，关闭未保存对账前可继续核对或放弃。本页按填写实际余额、勾选账单流水、核对差额组织；余额基准、手动勾选净额与自动计入的资产转换分别说明。普通完成只确认已有流水，显式选择“余额调整”才新增调整记录。余额起点另走预览与核对，普通资料编辑不修改原起点。

定投计划可查看、编辑并进入“登记本次买入”，实际成交在转换表单中核对。资产转换在桌面默认显示记录时间线，持仓概览仍可切换查看；复杂新增／编辑进入完整主区，保留手续费、连续步骤、保留数量及成本依据。

资产总览分别展示金融资产估值与原币数量，缺价部分保留数量并明确提示；资金账户不与已含账户余额的持仓重复相加。物品参考残值及使用成本在物品页查看。物品桌面清单便于比较，进入详情后按概况、使用与成本、配件耗材、记录与凭证组织，继续使用原有指标单位和生命周期控件。

游戏记录先查看，再明确编辑；游戏币数量、原币结算和缺价提示各自列出。操作历史采用完整列表／详情往返，差异与撤销继续使用审计记录。报表在宽窗口并排放置期间走势和构成，保留统一期间、下钻与精确明细。
