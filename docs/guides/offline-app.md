# 离线应用资源与更新

生产 Web 构建生成 `sw.js`，以普通应用静态资源内容摘要区分版本。首次联网加载后，浏览器安装应用的 HTML、JavaScript、CSS、WASM 和其他必需构建资产；任何必需资源下载失败，该版本不激活。大体积 OCR 模型和执行资源使用独立按需缓存，不在首页安装时下载；完成一次识别资源准备后才可离线识别，详见[本机截图识别](local-order-ocr.md)。开发服务器和 Tauri 原生壳不注册 Service Worker。

网页版断网重开依赖浏览器的 Service Worker：公网应使用 HTTPS（本机 `localhost`／回环地址可用 HTTP）。普通局域网 HTTP 地址没有此能力，不能因为已经能在线记账就认为已准备好离线启动。必须在同一浏览器、同一网站地址完成资源安装；首次访问、换域名／端口、使用新的浏览器或清除网站数据后，均需要重新联网准备。

缓存只保存构建时确定的公共静态资源。`/api/`、`/admin/` 请求及附件、用户导出文件不进入 Cache Storage，不缓存账号验证结果或托管凭据。账本缓存及离线授权仍遵循账号隔离与解锁规则。

安装成功且用户曾用账号密码登录并打开账本后，完全断网新开网页可用同一账号密码解锁已有账本。可在“设置 → 解锁与安全”开启“离线打开时免输密码（7 天）”，在该期限内免输账号密码；到期后仍可用账号密码离线打开。联网时登录状态有效即可直接打开账本，不依赖此选项。手机浏览器和添加到主屏幕的网页版遵循相同规则。首次注册、首次登录以及没有事先缓存资源的浏览器仍需联网。用户清除网站存储会同时失去离线资源和本机账本副本。

服务器停机时，本机账本仍可查看、记账并保存，关闭网页后重开也保留未同步记录。跨设备同步、服务器上的账号管理及尚未下载的附件需要恢复连接。记账入口统一为网站根路径（例如 `/` 或 `/ledger/`）。旧 `/app`、`/app/` 及其子路径已关闭，返回 404，不再跳转或提供离线页面；旧书签需改为根入口。

更新下载完成后显示提示，用户保存操作、关闭本站全部旧页面后，浏览器才启用新版。不会强制刷新正在填写的表单，不让旧页面与新资源混用；激活后只清理同一部署路径的旧静态缓存，不清除数据库、密钥或其他网站缓存。

`offline-cache.spec.mjs` 验证真实离线关闭页面再新开、解锁和重新联网，以及 Cache Storage 不含 API URL；`offline-update.spec.mjs` 验证 `/ledger/` 部署前缀、多个旧页面等待更新、激活后保留原账号与记账记录，并检查旧 `/app/` 入口在应用资源已缓存时仍返回 404。

`offline-server-stop.spec.mjs` 直接关闭测试 HTTP／同步服务器，保留浏览器在线状态，验证根目录和 `/ledger/` 部署下的继续记账、未预先打开页面的资源加载、关闭页面后冷启动、免密／密码解锁及刷新后的记录持久化。离线冷启动仅覆盖现行根入口。
