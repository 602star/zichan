# 设置中的数据保护

备份、同步、恢复与安全都位于“设置”页面，不占用侧边栏模块。页面采用同一级标签：记账、本机备份、服务器与同步、恢复数据、解锁与安全、外观。账号页的“查看数据保护与副本状态”直达“服务器与同步”；数据安全提醒直达“本机备份”。旧的 `sync` 页面状态进入设置页的服务器标签，已有导航偏好中的 `sync` 项会自动移除。

各标签按任务组织：

| 位置 | 内容 | 主要用途 |
| --- | --- | --- |
| 本机备份 | 正在使用的本机账本、本机自动与手动备份、外部目录及导出 | 离线记账、快速回退和另存独立副本 |
| 服务器与同步 | 客户端连接、管理员同步组、浏览器同步的独立服务器 | 多网页同步和跨服务器副本 |
| 恢复数据 | 本机与服务器备份的统一选择器；按需展开服务器备份管理 | 选择恢复点与恢复方式，先校验和演练，再确认导入 |
| 解锁与安全 | 账本密钥、恢复码、设备离线访问与应用锁 | 控制解密及失去设备后的恢复能力 |

“同步状态”仅表示当前客户端的同步结果；“服务器上的账本”按同步组的实际成员与账本健康结果显示各节点状态，单机时只说明尚无其他服务器副本，读取失败时显示待核对。副本组 `READY` 需要单独核对提交、删除状态和承诺附件；备份可用性通过归档校验及恢复演练确认。三者不能互相替代。服务器加入与复制链路管理位于管理后台，普通用户页不要求手动选择源节点或中继。桌面端便携目录中的 `data/backups` 与主数据一起移动，仍属本机备份；只有另存到其他介质或服务器的副本才提供位置独立性。

用户也可在“客户端同步与服务器连接”新增一台独立服务器，登录其尚未记账的账号，再选择“添加为浏览器同步副本”。当前浏览器把加密账目和图片传给两边，平时增量同步，首次连接和每日核对完整目录；两台服务器不会为此建立后台链路。关闭网页时跨服务器传输暂停，重新打开并登录后继续。目标服务器账号独立于原服务器：首次连接时需输入该账号的密码，密码或找回方式此后仍分别由各服务器管理。

附件以 4 MiB 密文块传输。上传重试会询问服务器缺少哪些块；下载重试从当前账号的浏览器存储读取并验证已收密文块，只下载缺失块。设置页在传输时显示当前附件的字节进度、百分比和已续传量；文件完成后清理下载暂存块。浏览器存储空间不足时，下载仍可尝试完成，但可能无法保存新的续传断点。

恢复选择器的“精确恢复”会把备份之外的数据标记删除并继续同步；“合并导入”保留当前独有的数据。两种方式均沿用已有的归档校验、恢复演练、恢复前保护备份和最终确认流程。服务器备份列表按需读取，避免每次打开页面都下载归档；选择恢复后才下载并验证选中的归档。

服务器之间的复制、附件分块传输、备份保留与密钥协议仍由现有模块执行。
