# 智能预选分类

新建支出时，无需先输入描述，表单会按交易时段和本账本的习惯预选分类。午间 11:00（含）至 14:00（不含）优先预选“外卖”；分类旁说明预选原因，仍可直接修改。电脑与手机的完整记账表单共用策略，快速支出组件也使用相同逻辑。

## 默认选择顺序

1. 本机设置的个人时段规则。
2. 近 60 天同类日同时段的稳定习惯。
3. 内置的早餐、午间、晚餐或夜宵分类。
4. 你设置的固定默认、最近一次可用支出分类，最后使用“其他支出／待分类”。

习惯统计区分周一至周五和周末，采用目标时刻前后 90 分钟的有效支出；日期精度记录不参加时段统计。至少 5 笔样本，第一位分类至少 3 笔、占比不低于 60% 且领先第二位至少 2 笔时，优先使用该习惯。正常记账即可积累，无需点击学习。作废、删除、退款、未来日期和不可用分类不作为习惯证据，查询不受流水筛选或 1000 条列表上限影响。

## 手选与补记

手选分类、模板、恢复的草稿、编辑已有流水，以及连续记账主动保留的分类不被自动覆盖。表单开着跨过午间时段也不会自己跳分类。

修改交易日期或时间后，尚未手选的分类按这笔交易的时间重新判断。补记历史消费而未提供有效时间时，不用现在的午间时间猜分类。收入和退款继续使用各自的类别范围，不套用外卖默认。

隐藏、停用和未启用的目录分类不主动预选。外卖不可用时回退到可用的工作餐或普通餐饮，不自动启用分类。

## 本机设置

打开“设置 → 记账 → 智能预选分类”：

- “按时段和习惯预选分类”默认开启，关闭后使用固定默认分类。
- “默认支出分类”用于关闭智能预选，或没有匹配时段和习惯的情况。
- “添加时段规则”可设置起止时间及分类，支持跨午夜，开始和结束不能相同。重叠规则按页面顺序采用第一条；结束时间不包含在范围内。
- 点击“保存本机预选设置”后生效；显示“已保存在本机”才代表保存成功。

设置按当前账号的本机分区保留，不写入账本设置、同步提交或服务器，也不会改变历史流水。服务器管理员只读预览不能修改这些设置。

本说明覆盖情境默认分类。[本机截图识别](local-order-ocr.md)另支持金额／日期核对、日常收支新图片脱敏及订单／物流号可选本机保留；这些能力不自动按商品改分类。描述／商品语义分类仍在[后续方案](../planning/local-order-capture.md)中。
