# 周期报告与记账提醒

云同步账号可以在 **账号 → 报告与提醒** 中开启周期统计报告与习惯提醒，支持 **HTML 邮件** 与 **Bark / Webhook 多渠道推送**。

## 前置条件

1. **托管模式**：服务端定时统计需要在服务器内存中临时解密并重放提交（明文绝不落盘），仅对开启了托管模式的云同步账本生效。
2. **投递渠道**：
   - **HTML 邮件**：需先在「账号 → 邮箱」中绑定并验证邮箱，且服务器管理员已配置可用的 SMTP 发信渠道。
   - **其他推送渠道**：可直接在「报告与提醒」中添加最多 5 个推送渠道，支持 Bark、飞书、钉钉、企业微信、Discord、Slack、通用 JSON Webhook 与纯文本 Webhook。Bark 的设备密钥在服务端脱敏保存，界面回显为 `********`。

## 支持的报告与提醒类型

所有开关默认关闭，均按用户自选时区（默认 `Asia/Shanghai`）判定发送时间，并按周期唯一键幂等去重，避免重复发送。

- **日报**：汇总当日收支、活跃天数、分类支出 Top 5 与大额支出 Top 3。若发送时段早于 12:00，则自动统计前一日；支持「当日无交易时不发送」。
- **周报**：在指定星期与时段发送上一完整自然周（周一至周日）的汇总及环比变化。
- **月报（智能发薪月 / 固定发薪日 / 自然月）**：
  - **智能发薪月（推荐）**：无需手动填写发薪日，自动识别账本中的「工资 / 薪资」类收入流水，以「上次发薪日至本次发薪前一日」为一个周期（如遇节假日提前或顺延发薪也能精准切分；15 天内的基本工资与绩效工资自动合并为同一期），记入新一笔薪资后自动发送上期月报。
  - **固定发薪日**：自定义每月发薪日（1~31 日），周期为「上月发薪日（含）至本月发薪日前一日（含）」（例如发薪日 10 号对应 `上月 10 日 ~ 本月 9 日`），遇到小月自动对齐月末，在发薪日当天发送。
  - **自然月**：每月 1 日发送上个自然月（1 日至月末）的统计。
- **连续未记账提醒**：当最近一笔有效流水的日期距今达到设定天数（默认 3 天）时触发提醒，并按冷却间隔（默认 3 天）防止每日重复打扰。空账本不会触发提醒。
- **账单还款到期提醒**：检测信用卡与贷款账户的还款日，在到期前 `N` 天（默认 3 天）提醒。
- **定投计划提醒**：检测活跃的自动定投计划中尚未执行的期次，在到期前 `N` 天（或已逾期时）提醒。
- **日历生日与纪念日提醒**：结合首页日历中的阳历与农历生日、纪念日，在到来前 `N` 天（默认 3 天）提醒。
- **预算超支预警**：监控当月分类预算执行率（自动汇总子分类支出并扣除退款），达到预警比例（默认 80%）或 100% 超支时即时推送，同一分类同一档位当月只提醒一次。
- **物品耗材与质保到期提醒**：检查在用物品资产的质保、维保、退货/价保截止日期以及耗材剩余寿命，在到期前 `N` 天（默认 7 天）或耗材低于预警余量时提醒。
- **隐私模式**：开启后邮件与推送中的具体金额会替换为 `****`，仅保留记账笔数、活跃天数与环比百分比。

## 测试发送与记录

在设置页可点击「保存并立即测试发送」，选择日报、周报、月报或未记账提醒，立即按当前配置生成并投递至所有已启用渠道，并查看逐渠道回执与最近发送记录。
