# 账单与还款

账单计划独立于资金账户。不需要先添加银行卡、钱包或信用卡，也能记录房租、水电、订阅、保险、借款还款和分期等事项。

## 添加计划

- 电脑：日常 → 账单与还款。手机：更多 → 账单。首页“账单与还款”卡片也提供“新增账单”。
- 可直接新增，或选房租、水电燃气、订阅续费、信用卡还款、借款还款和分期付款预填名称，名称仍可自由修改。
- 填写计划金额、币种和首次日期；频率支持仅一次、每天、每周、每月和每年。
- 分期等有限计划选择“固定期数”，填写每期金额及总期数；系统依据日期规则保存结束日期。月度计划自动处理短月和月底，期数包含首期，不计算本金、利息或费用分摊。
- “关联资金账户”默认关闭，仅在希望追踪资金账户时选填。选择账户间转账时才需要明确双方账户。

保存计划本身不会新增收支。默认不自动入账；如果在更多信息中启用自动补齐，应用会在打开时生成到期流水，不代表自动付款。

## 处理本期

**仅标记已处理**：用于已在别处完成、已由其他流水记录或只需提醒的账单与还款。记录处理时间并推进到下一期，不生成流水、不修改账户余额，也不重复计算支出。处理后短时间内可通过提示条撤销；撤销只恢复本期提醒。

**登记流水**：按计划的入账类型、分类及金额写入真实收支或转账。可不关联资金账户；计划金额与实际情况不符时先编辑计划。已标记处理或已生成的同一期不能重复登记，多窗口操作也共享同一期的处理锁。

单次账单处理后显示“计划已完成”；固定期数计划在最后一期后结束。计划日已过只表示待处理，不据此推断仍未付款。处理历史区分已生成流水、失败和未入账的标记／跳过；具体动作可在操作历史查看。

## 首页提醒与原有数据

首页同时显示独立账单计划和可选的账户还款日期，按今天提醒，独立于统计期间。信用卡账户日期只是额外来源，不是使用账单或记录还款的前提，也不自动提供每期应还金额或还清状态。

沿用已有计划、期次及审计记录，单次与固定期数使用原有起止日期表达。无需重置数据库；原有账单、备份和同步数据继续兼容。
