# 分类选择器布局约定

分类选择入口统一使用 `EntityFormModal.tsx` 的 `CategoryPicker`，表单通过 `type: 'category'` 接入。一级分类、类型等单层选择仍可使用原生 select。

## 布局和交互

- 输入框宽度属于表单，选择面板宽度属于组件；调用方不传最小面板宽度，不扩大业务弹窗解决选择器溢出。
- 面板通过现有 DialogShell 挂载到浮层，沿用主题、嵌套层级、焦点约束与焦点恢复。Escape、关闭、点击外部只关闭选择面板。
- 面板宽最多 540px、高最多 420px，按内容自然收缩并保留视口边距；根据触发位置选择上下展开并水平避让，使用所选方向的可用高度，保持贴近触发框。监听内容尺寸、滚动、窗口及 visualViewport 变化。
- 手机也使用紧凑下拉面板；常规手机保留两栏，面板内容宽度不足 338px 时一级和二级分步显示，提供返回入口。隐藏步骤同时设置 hidden，避免键盘访问不可见选项。
- 顶部仅保留搜索和图标关闭，隐藏范围开关按需显示。普通选项使用正常字重，仅选中项强调。二级名称完整换行，选项采用最小高度而非固定高度。搜索结果单列显示父级与子级完整路径，状态标记保留。触发框允许已选值换行。
- 不改变隐藏、停用、未启用目录分类的业务范围：写入入口和历史筛选分别提供自己的选项。

## 接入清单

表单的 12 个分类字段：交易模板、交易对象默认分类、日常收支（含退款）、拆分明细、分类预算、定期交易、游戏结算分类、游戏手续费分类、物品分类、物品购买流水分类、物品生命周期事件流水分类、耗材流水分类。

直接入口：快速支出组件、流水筛选、高级查询、批量修改；新增统一入口：物品列表筛选、历史记录整理分类筛选。

## 防回归

`tools/e2e/tests/category-layout.spec.mjs` 使用真实组件验证：

- 320、390、768、1280px 视口，130px 窄触发框，真实半宽交易对象表单。
- 右下角触发、窗口缩小、640×400 的缩放等效布局；该等效布局不替代真实浏览器 200% 缩放验收。
- 超长自定义分类和隐藏标记、完整路径搜索、点击命中、面板不越界及不横向裁切。
- 返回一级、选择后焦点恢复、Escape 保留外层表单及输入。
- 流水筛选与高级查询接入。

新增分类入口需进入该清单，并复用组件，不另写宽度补丁。布局验证须检查边界、文字溢出与点击命中，不能仅断言选项存在。浮层已通过 portal 独立渲染，测试应按「选择分类」dialog 定位，而不是从父表单查找其 DOM 子节点。
