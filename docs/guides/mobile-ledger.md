# 移动端页面与操作

手机 Web 与 Android 壳共用 `apps/web` 页面和组件，沿用“大福帳 · 墨与朱”的文献纸、文楷标题、墨线和朱色操作。页面组已接入真实账本，包括下列导航、目录、详情和编辑流程；此前的独立 HTML 原型仅作设计参考。

“设置 → 记账 → 新手指南”可随时重看教程，保留已完成步骤。手机逐步说明记账弹窗、常用账户、分类和模板，最后在“找到常用功能”展开账单、物品和备份说明，进入对应页面。每步提供实际操作说明，可跳过并保留位置，切换到电脑宽度也继续当前步骤。“暂时收起”可从流水页继续；“完成引导”会保存完成状态，并移除流水页的指南入口，刷新后不再显示，仍可从设置重看。电脑侧栏的工作台在手机称总览，流水在底栏称收支；手机底栏不随侧栏显隐或排序改变。

## 导航和页面

收支列表按日期使用轻卡片，默认展开含今天的近 7 天，更早日期只显示笔数与当天收支合计；支持逐日切换、全部展开和全部折叠。单条记录首行展示分类与原币金额，摘要、账户和时间在后续行。所选月份及其他查询范围自动加载全部流水，不需要点继续加载；搜索筛选后自动展开命中日期，折叠不会影响统计。详情、长按、左右滑动及退款操作继续沿用原有流程。

底栏固定为总览、收支、记一笔、资产、更多。从报表等其他页面记一笔时，使用真实收支表单，保存或关闭后留在原页面。手机页面与弹层维护浏览器历史，返回先退出当前层；未保存的通用表单和转换表单继续提供草稿保护。

| 入口 | 页面与操作 |
| --- | --- |
| 总览 | 默认显示所选期间支出、收入和结余；最近流水可进入只读详情；设置中可切换为资产优先 |
| 收支 | 流水、账户、预算、账单与还款；预算详情及编辑、账单详情及生成本期流水 |
| 资产 | 账户／持仓／物品；账户原币余额与账户流水；持仓数量、估值、成本与缺价处理 |
| 物品 | 默认卡片，可切换清单并记住选择；详情按概况／使用与成本／配件耗材／记录与凭证组织，事件入口支持配件处置与订阅服务费用 |
| 报表 | 收支／游戏／物品等报表、期间筛选、分类下钻与明细；导出面板提供 CSV、PDF 和流水明细 |
| 转换 | 持仓与转换历史；单笔或连续步骤、手续费与收付；手机新增转换先核对实扣与到账，再确认保存 |
| 游戏 | 游戏与赛季、投入回收；点记录看详情，再进入编辑；缺价记录明确提示尚未完整估值 |
| 资料管理 | 按收支分类、标签与交易对象、模板、资产、账户、价格、物品分类、计划、游戏资料、附件进入独立页面 |
| 操作历史 | 搜索筛选后进入独立详情，继续查看字段差异、撤销和冲突处理 |
| 设置与账号 | 按任务进入记账、外观、备份、同步、恢复和安全；个人资料、邮箱、账号安全与配额各有返回路径 |
| 登录和首次使用 | 手机登录、注册、找回账号分开呈现，继续使用原有服务器认证与初始化流程 |

“更多”按查看与计划、账本资料、我的与设备分组。桌面侧栏的可见项单独配置，手机不再随侧栏配置变换底栏。管理维护功能从目录逐层进入，图表、效率分析和设备技术信息按需展开。

## 查看、编辑和退款

- 点按流水或“详情”查看只读详情，展示原币金额、分类、账户、状态及已有的交易对象、标签、拆分、地点、附件数量和备注。
- 长按约 500ms，或向左／向右滑动至少 56px，打开“流水操作”。滑动只唤出选择，不直接保存、作废或删除。
- 行尾的更多按钮提供同一入口；键盘聚焦行后可以按 Shift+F10 打开操作，Enter 查看详情，Escape 关闭面板。编辑与退款继续使用原有表单和校验；对账调整仍进入关联对账。
- 支出按剩余可退金额提供“记录退款”，已有退款保留“查看退款记录”和行内退款徽章。全额退款后仍能查看、作废关联退款。
- 桌面保留点按行打开编辑的原有操作方式。

手势忽略复选框、按钮等交互控件。纵向滚动、第二根手指、失焦或系统取消触摸会取消长按；屏幕左右各 24px 不识别流水手势，留给系统返回。短横滑不触发编辑，也不误算成点按。

## 按天读账

每天以 1px 墨线和日期分隔，右侧显示“支出合计”和报表币种；完整记账模式同时显示收入。金额沿用 decimal.js 与资产精度，不经过 JavaScript 浮点计算。

小计跟随当前筛选，使用完整 SQL 聚合，不只加总已加载的一页。退款按账本的退款归属设置冲减支出，转账不计入收入或支出。退款日归属下出现负支出时保留负号。某一天包含无法折算的金额时，该天标记“未完整折算”，并保留页面原有缺价提示与处理入口。

## 共用控件

长表单按记录内容、金额与账户、日期与周期、其他信息分组；原有附加字段与校验保留。单值选择在手机使用纸面选择面板，长选项列表提供搜索；桌面保留原生 select。新增账户的余额时间在手机拆成日期、时间两个共用选择器。保存区留在手机表单底部，正文独立滚动。

`ui/ActionSheet.tsx` 通过原有 `DialogShell` 共用主题门户、背景滚动锁、焦点限制和关闭后焦点恢复。手机贴底并留出安全区；窄屏和低高度时面板内部滚动。面板用纸面、8px 顶角、宋体标题、等宽数字和 1px 分隔，不在内部再套卡片。关闭目标至少 44px，操作行至少 56px。日期与时间继续使用已有墨朱选择面板，桌面保留键盘输入。

## Android 真机验收（待执行）

浏览器触摸模拟不能代替以下真机检查：

- 滚动过程中不误触长按；左右滑动可打开操作，系统边缘返回优先。
- 返回键先关闭操作面板或编辑表单；有未保存内容时遵循原有离开保护。
- 软键盘不遮挡金额、保存按钮，日期选择不同时唤起键盘。
- 附件相机、相册、文件权限的允许、拒绝及重新授权；保存、分享和取消文件选择。
- 安全区、横竖屏、大字体、屏幕阅读器和焦点顺序。
- 编辑时切到后台再恢复，面板、草稿及锁定行为正常。

回归入口：`tools/e2e/tests/mobile-pages.spec.mjs`（真实页面组）、`mobile-record-actions.spec.mjs`（手势）、`mobile-datetime-summary.spec.mjs`（日期与汇总）、`card-system.spec.mjs`（三纸张／明暗／尺寸）、`conversion-balances.spec.mjs`（连续转换）。具体页面交付与验证记录见[落地清单](../planning/mobile-pages-implementation.md)。
