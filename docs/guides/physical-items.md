# 物品资产：整理、使用与维护

物品页用一份档案贯通购入、使用、维护、配件和处置。电脑以比较清单为主，手机按记录重排；可切换照片卡片，详情占用完整主区。页面沿用纸张、墨朱、文楷与共用卡片、分类、日期、附件控件。

手机保留搜索、状态与待处理摘要，分类／年份／位置等组合条件折叠展开；日历和时间线通过视图选择器进入，避免控件占满首屏。未设置的使用指标直接提供“添加使用指标”入口。

## 找到物品

- 按购置年份、存放位置、二级分类、使用状态及待处理情况组合筛选。使用中、闲置、已处置分别筛选。
- 位置支持“家 / 卧室 / 衣柜”等层级，选择上级会包含下级。位置名和分类分别管理；位置可改名，或归档整个位置分支并将物品迁移到另一处。
- 物品名下直接显示购置年份与位置。搜索支持名称、品牌、型号、序列号、条码、标签和位置路径。
- 普通筛选在当前账本会话中保留；需要长期使用时保存为常用视图，随账本备份与同步。可按购入时间、名称或净投入排序；净投入按币种分组比较。
- 已归属配件费用计入整机，清单默认不重复展示为独立物品；可展开查看配件。安装中的配件位置随整机展示。

## 录入与资金处理

- 新增物品填写名称、分类、购买信息与位置；品牌、保修、设备码和凭证按需要补充。相同分类可沿用上次使用的位置。
- “从支出登记”先选择现有支出，带入名称、日期、币种和金额，再确认物品分类、位置及分配金额。关联现有支出不再次扣款；一笔订单包含多件物品时，应分配各自金额，服务端继续校验可分配余额。
- 资金处理继续使用“仅登记、关联已有流水、同时创建流水”。购买、维修、升级、耗材和出售沿用已有事务及补偿逻辑。
- 旧物可选择“只记年份”。年份是明确标记的低精度日期，不作为已知购买日；日均和持有天数显示待补日期。明确的启用日期仍可作为日均起点。
- 年份记录在数据库中使用该年年初作为存储边界，并携带 `purchaseDatePrecision: year`。展示和导出明确标注日期未补；未补日期的购入事件不进入逐日时间线、月历或单日。补齐准确购买日期后才能关联购买资金；已有购买资金关联的物品不能改为只记年份。

## 物品详情

- **概况**：净投入、持有日均、主使用指标、位置、购买档案、参考现值，以及净投入来源。净投入只扣实际回款，参考现值不参与抵扣；持有天数包含闲置期间。
- **使用与成本**：次数、公里、小时及自定义指标，用量记录、冻结成本基数的目标。未记录用量时显示待记录，不把单位成本显示为零。
- **配件耗材**：购入配件、登记原配件、安装／拆下／转装、升级支出转配件，以及耗材寿命和更换管理。
- **记录与凭证**：生命周期事件、关联资金说明、位置变更，以及照片、发票、保修凭证、说明书。位置历史保留变更时的路径名称。

## 待处理与保养

保修、退货、价保和保养日期可设置提前提醒天数，默认为 7 天。耗材继续按已登记的用量与提醒阈值生成待办。物品页可只看待处理，总览待办可直接进入对应物品。

保修、退货与价保只在尚未结束的提醒窗口展示；保养逾期仍保留。已处置或已归档物品不再生成日期待办。完成保养需确认，写入一条零费用的完成记录；填写保养间隔时按实际完成日生成下次日期，不填写则清除本次待办。实际费用另记维修支出。

## 批量整理与导出

勾选当前结果可批量改位置、修改分类或归档。批量操作在单一事务中校验版本，任一物品已变更则整体失败，避免只改一部分。归档保留历史和资金流水。

CSV、PDF 导出默认使用当前筛选结果；勾选后使用所选范围。导出保留原币金额、日期精度和位置，不将多币种或已归属配件重复汇总。CSV 对用户文本做公式转义。

## 使用费用：电费与充电

从物品详情点“记录使用费用”，或进入“使用与成本”的使用费用区。它与次数／里程／小时等使用量指标、滤芯等耗材分开管理。

- **直接记费用**：只有账单金额时，直接登记电费、停车费等使用费用。
- **按用量记录**：电车每次充电可填度数（kWh）、本段单价及服务费；有订单总金额时，以总金额替代计算值，不再加一次服务费。只有度数时也能保存为“费用待补”，以后编辑补价；它不表示免费。
- **累计计量**：添加计量项目，填设备自带统计或外接电能表的起始累计电量；起点之前的读数不计费。随后每次“抄表计费”只计算与上次起点／读数的差值。这里填写电量 kWh，不是瞬时功率 W。本期单价独立保存，电价变化时先抄表划段，不会追溯修改旧费用。同一天可以按操作先后登记多条。
- **暂停与恢复**：拆掉电能表时点“暂停计量”，可填写末次读数结清测得部分；未填写则从最后一次读数起标记未计量。暂停不表示设备停用，也不自动补零。重新安装后用当前读数“设置起点并恢复”，不跨暂停期扣读数；历史记录保留空档起止日期。空档可另记实际账单，或填写明确日期范围与合计用量／金额的估算。
- **换表／归零**：先记录旧表末次读数，再以新表读数设新起点。没有结清的部分标记未计量，不计算负用量，也不推测旧表终值。
- **估算参考费用**：明确选择估算并填写日期范围、合计估算用量和单价／金额。估算单独展示，不进入净投入、日均和单位成本，也不能关联资金流水；已有同名、同单位项目的计量／估算覆盖时会阻止重复估算。补录测得用量前先删除重叠估算。系统不自动按一次功率读数推算终身耗电。

已登记的实际使用费用计入物品净投入及日均／单位成本，已归属配件的费用随整机汇总；数量与费用未知状态分别保留。费用区按单位显示“已记录用量”，它不是设备终身总耗电，也不混加不同单位。

使用页只显示当前计量状态和最近 **3 条**费用记录，不随抄表次数追加长列表。“查看全部使用费用”进入“记录与凭证”，自动筛选费用与抄表；“处理待补费用”直接找到历史未定价用量。历史可按记录类型、月份、费用项目组合筛选，**每页最多 10 条**，翻页替换当前记录，不无限追加；累计费用和用量不受当前页影响。原次数／里程／小时使用记录也只预览最近五条，完整记录同样在历史中分页查看。仅记购置年份的购买记录保留在全部历史，不伪造所属月份。

实际费用沿用“仅登记、不影响余额／关联已有流水／同时创建流水”。家庭电费已经在流水记账时，选择关联已有账单并分配本设备对应金额；一笔账单可分配给多个物品，但不能超过其可分配金额。**同一段用量的账单费用与抄表费用选一种登记**，系统不能从未标期间的手工金额判断是否重复。估算、未定价用量及计量起点不能创建或关联付款。

历史记录可补单价、金额与备注。若后续读数依赖该记录，改读数或删除需从最新一条往前处理，避免静默改写后续费用。另一窗口新增了读数后，旧表单会要求刷新核对；删除只补偿由该记录创建的付款，关联的原账单保留。

数据来源目前由用户手动填写，尚未接入设备、充电运营商或智能插座接口。

## 数据兼容

schema 129 在原物品元数据上增加可空的版本化使用费用记录列。对已知 schema 127／128 验证结构后事务升级，保留原有物品、设置和资金记录；不自动重置数据库。位置、常用视图、提醒、计量与费用记录均随原有账本导出、恢复和同步。

借用归还、二维码标签、订单识别及物品 CSV 导入留作后续功能；当前扫码设备码、照片与凭证管理继续使用已有能力。
