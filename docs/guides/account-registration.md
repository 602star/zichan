# 账号注册与个人资料

## 当前交互

注册顺序为昵称、登录账号、密码、确认密码，服务器要求时再输入邀请码。登录页只填写登录账号与密码。

| 字段 | 用途 | 规则 |
| --- | --- | --- |
| 昵称 | 页面显示名与默认头像文字 | 1–24 个字符，支持中文，可在「我的账号」修改 |
| 登录账号 | 登录和服务器内部同步身份 | 2–64 个中文、字母、数字或 `_`、`.`、`-`；注册时按 NFKC 规范化并转小写，注册后暂不提供修改 |
| 密码 | OPAQUE 登录凭据 | 至少 8 个字符，客户端不上传明文密码 |

已有账号没有昵称时显示原登录账号。默认头像用昵称首字生成，不要求上传照片，也不增加图片存储与同步负担。服务器的 `accountId` 继续作为稳定账号标识；昵称变化不影响登录、加密账本或同步绑定。

「我的账号」页面集中展示资料编辑、当前服务器的加密记录与附件配额、密码、登录设备和退出入口。配额只按当前登录账号查询，普通用户与只读运维显示已用、上限、剩余和占比，所有者与管理员显示无限配额；附件数字包含有效附件、回收站与暂存上传。其他同步服务器各自有独立配额，在对应服务器登录后查看。

## 可选邮箱与通知

注册时不要求邮箱。「我的账号」可添加或更换邮箱：服务器发送 8 位验证码，10 分钟内有效；同一账号每分钟最多发送一次、24 小时最多发送 5 次，同一个验证码最多尝试 5 次。验证码摘要保存在服务器；更换邮箱后，新地址需要重新验证，旧地址在完成验证前仍保持已验证状态。

邮箱验证后，用户可以自行开启「配额接近上限」邮件提醒，默认关闭。服务器容量告警进入活动状态时，每次告警只入队一次；后台发送任务失败后重试，最多尝试 5 次。关闭提醒或移除邮箱会跳过尚未发送的邮件。邮件只提示配额类别和占比，不包含账本金额、交易记录或附件内容。

服务器管理员需要先在 `alertChannels`（`ADMIN_ALERT_CHANNELS`）中配置已启用的 SMTP 邮件渠道；账号邮件强制使用 TLS/STARTTLS，没有可用渠道时页面会说明原因。已验证邮箱、待验证地址和通知偏好由服务器保存。邮箱目前仅用于提醒，**不用于登录或密码找回**；密码找回仍采用现有管理员审核流程。
