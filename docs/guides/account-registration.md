# 账号注册与个人资料

## 当前交互

注册顺序为昵称、登录账号、密码、确认密码，服务器要求时再输入邀请码。登录时可填写登录账号或已绑定邮箱，再输入同一账号密码。

| 字段 | 用途 | 规则 |
| --- | --- | --- |
| 昵称 | 页面显示名与默认头像文字 | 1–24 个字符，支持中文，可在「我的账号」修改 |
| 登录账号 | 登录和服务器内部同步身份 | 2–64 个中文、字母、数字或 `_`、`.`、`-`；注册时按 NFKC 规范化并转小写，注册后暂不提供修改 |
| 密码 | OPAQUE 登录凭据 | 至少 8 个字符，客户端不上传明文密码 |

已有账号没有昵称时显示原登录账号。默认头像用昵称首字生成，不要求上传照片，也不增加图片存储与同步负担。服务器的 `accountId` 继续作为稳定账号标识；昵称变化不影响登录、加密账本或同步绑定。

「我的账号」页面集中展示资料编辑、当前服务器的加密记录与附件配额、密码、登录设备和退出入口。配额只按当前登录账号查询，普通用户与只读运维显示已用、上限、剩余和占比，所有者与管理员显示无限配额；附件数字包含有效附件、回收站与暂存上传。其他同步服务器各自有独立配额，在对应服务器登录后查看。

## 可选邮箱与通知

注册时不要求邮箱。在「我的账号 → 邮箱与通知」填写地址并点击「绑定邮箱」即可，无需管理员先配置邮件服务，也无需验证码。地址按 NFKC 规范化并转小写，每个邮箱在本站只能绑定一个账号；绑定后显示「未验证」，立即支持「邮箱 + 原账号密码」登录。原登录账号仍可使用，账号和账本身份不变。记账登录、同步连接和管理后台登录均接受已绑定邮箱；管理员的两步验证要求不变。

邮箱所有权未验证时，地址只作为密码登录别名，不能用于邮件找回或提醒。更换绑定邮箱立即停用旧邮箱登录，清除原验证状态、待验证代码和已发出的邮件重置码，并关闭提醒；移除后请使用原登录账号登录。相同地址重复保存会保留已有验证状态和通知偏好。旧版本允许重复的通知地址保留，但发生重复时不支持邮箱登录；用户仍可用原登录账号登录并更换邮箱。

邮件服务开启后，未验证邮箱旁提供「发送验证邮件」。服务器发送 8 位验证码，10 分钟内有效；同一账号每分钟最多发送一次、24 小时最多发送 5 次，同一个验证码最多尝试 5 次。验证码只保存摘要，更换绑定或移除邮箱不会重置发送限额。

邮箱验证后，用户可以自行开启「配额接近上限」邮件提醒，默认关闭。服务器容量告警进入活动状态时，每次告警只入队一次；后台发送任务失败后重试，最多尝试 5 次。关闭提醒或移除邮箱会跳过尚未发送的邮件。邮件只提示配额类别和占比，不包含账本金额、交易记录或附件内容。

只有验证码、邮件找回和提醒需要管理员在 `alertChannels`（`ADMIN_ALERT_CHANNELS`）中配置已启用的 SMTP 邮件渠道，账号邮件强制使用 TLS/STARTTLS。未开启邮件服务时，绑定和密码登录照常可用。已验证邮箱支持现有「忘记账号密码」邮件找回流程；没有已验证邮箱时仍使用管理员审核重置。邮箱绑定按节点管理，统一账号在创建账号的身份源节点管理邮箱；不会自动把本站绑定地址作为其他节点的登录别名。
