# 账本保护与离线访问

新部署统一采用服务器托管账本密钥。账号注册或首次创建个人账本时，服务器生成随机账本凭据，并用部署的 `custody.key` 加密保存。获授权的同步组节点接收该凭据后各自封存；用户使用同一个账号密码登录任一可访问节点，客户端取得账本凭据并打开账本。独立服务器由用户浏览器连接并传送账本密钥，仍由目标服务器托管。

账本提交、附件与备份继续加密存储和传输。托管服务器具有解密能力，管理员后台的只读预览受权限及审计约束。本项目不再提供“私密模式”、恢复码或按服务器切换托管方式。当前仅提供个人账本，不提供成员共享入口。

## 默认离线访问

本机截图识别的订单号／物流号保留使用独立加密数据库，不注册为普通账本实体，不进入同步提交、审计、普通备份、设备恢复包或远程备份。图片附件只接收已核对的脱敏副本；本机号码与附件遮盖互不替代。此保护当前覆盖日常收支的新图片与显式本机保留选项，其他业务原有普通字段及历史附件行为不自动改变，详见[本机截图识别](local-order-ocr.md)。

用户用账号密码在线登录并打开账本后，本机会自动把解锁资料用该账号密码加密，按账号和副本隔离保存。断网或服务器临时不可用时，已缓存应用资源的网页版、手机 App 和桌面 App 可用同一个账号密码打开**本设备已有**的账本缓存，继续本地记账；恢复连接后再同步。用户无需设置第二个离线密码。

网页版成功打开后在后台自动准备“本机快速打开授权（7 天）”，下次优先打开本机加密账本，网络验证与同步在后台执行；可在“设置 → 解锁与安全”手动续期。期限从准备或续期时计算，缓存打开不自动续期。到期后仍可在线解锁或用已准备的账号密码离线打开；退出账号会清除本机授权。原生 App 的离线免密仍需手动开启，指纹、人脸或设备密码应用锁仍独立验证。详见[账本快速打开](ledger-startup.md)。

联网且登录状态有效时，直接打开账本即可，无需开启离线免密。Web 的在线记账会话采用 100 天闲置期限、登录起最长 365 天，与此处的 7 天离线免密分别计时；“7 天”不会缩短联网登录期限。手机浏览器及添加到主屏幕的网页版沿用同样规则。普通局域网 HTTP 网页无法保证完全断网后的重新打开，详见[离线应用](offline-app.md)。

首次登录、没有本机账本缓存、浏览器清除网站数据，或网页静态资源尚未安装时，都需要联网。没有有效本机授权时，401/403、账号变化或服务器身份变化不会触发离线入口。已有有效本机授权可以先打开缓存，后台登录失效会暂停同步并显示重新登录入口，本机记录继续保留。主动退出会清除本机授权；重新登录后自动准备。服务器暂时不可达时无法验证远端的密码变更或设备撤销，因此本机授权有效期内仍可打开已有副本。

Web 离线冷启动依靠生产构建的 Service Worker 缓存公共静态资源；API 响应和用户账本不放入 Cache Storage。本机加密账本保存在账号分区的 IndexedDB。详见[离线应用](offline-app.md)。

## 服务端与恢复

`CUSTODY_KEY_PATH` 默认指向 `DATA_DIR/custody.key`。服务器备份必须包含对应的主密钥；有托管记录而主密钥缺失时，服务器拒绝启动。`ACCOUNT_PROTECTION` 和 `CUSTODY_ENABLED` 配置已移除，所有新账本使用托管模式。

账号密码找回更新账号凭据，不改变账本身份或托管密钥。新密码在线登录后会重新创建本机离线解锁资料。导入备份沿用当前账号和账本的托管身份；导出的加密备份仍需其导出流程要求的解锁材料，不会额外生成私密模式恢复码。

### 附件识别规则更新（2026-11-26）

新增和编辑日常收支均从附件图片旁“提取信息”，电脑在当前图片下展开处理，手机进入全屏子页。可选择保留脱敏图片、保留原图或不保留图片；未处理普通附件沿用既有保存行为。订单号和物流单号现为普通流水字段，参与同步与备份，取代此前独立本机留存 UI。以上规则替代本页此前开发阶段提到的日常收支强制脱敏、仅本机号码保留或仅允许图片附件的限制；旧私密库不自动迁入普通流水。详见[现行操作指南](attachment-capture.md)。
