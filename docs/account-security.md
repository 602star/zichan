# 账号安全与所有者恢复

设置中的“账号安全”支持修改当前主账号密码、查询账号登录设备和撤销其他设备会话。修改密码需再次输入当前账号密码，经 OPAQUE 验证后取得五分钟内有效的一次性授权；新密码提交、旧会话撤销、待完成登录清理与审计记录在同一事务完成。账号密码不会发送明文或持久化。

密码修改不会改变账本身份、密钥、恢复码或托管方式。托管账号重新登录后自动恢复；私密账号仍使用原恢复码。退出会保留本机加密缓存和未同步记录。撤销设备不等于远程删除设备上已经保存的离线副本。

## 唯一 Owner 遗失密码

此能力仅提供给能访问服务器数据目录的本机部署者，不提供匿名 HTTP 认领接口。

1. 停止目标服务器，确认使用正确的数据目录。
2. 执行 `npm run maintenance -w @zichan/sync-server -- owner-recovery --data-dir <目录> --output <新的私有文件路径>`。
3. 命令只输出账号名、有效期和文件路径；一次性重置码写入指定的新文件，已有文件不覆盖。文件应置于仅部署者可读目录，不能放在 Web 静态目录或共享目录。
4. 重启服务器，在登录页“忘记账号密码”中填写返回的 Owner 用户名、文件内的 code 和新密码。
5. 成功后删除重置码文件。重置码十五分钟有效，重新发码使旧码失效，兑换只能成功一次；账号、角色及账本数据保留，全部旧登录失效。

数据库只保存码的 SHA-256 摘要，操作写入 `owner-recovery-local` 审计记录。服务器备份恢复会清除待兑换重置码并撤销旧登录，不能通过恢复历史备份复活已用重置码。
