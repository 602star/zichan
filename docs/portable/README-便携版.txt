资产生命周期 0.2.0 Windows x64 完全便携版
===========================================

一、启动

1. 先把 ZIP 完整解压到本地磁盘、移动硬盘或 U 盘，不能直接在压缩包内运行。
2. 保持 zichan.exe、portable-mode.json、server 和 runtime 的相对位置不变。
3. 双击 zichan.exe。首次启动会在同一目录创建 data 文件夹。

支持 NTFS 和 exFAT；不支持 UNC、网络共享和映射网络盘。目录不可写、资源缺失、
标记不匹配或同一目录已有一个实例运行时，应用会在写入账本前终止且不会回退到 AppData。

二、数据边界

账本、附件、备份、凭据、内置同步服务器和 WebView 界面状态全部位于 data：

  data\ledger       主数据库
  data\attachments  附件正文及暂存/回收状态
  data\backups      应用内 .zcbak 备份
  data\security     Stronghold 凭据库
  data\server       内置同步服务器数据库、身份密钥、账号会话和密文附件
  data\webview      localStorage、IndexedDB、表单草稿和 WebView 缓存
  data\logs         本机诊断日志
  data\runtime      当前目录的实例锁

整个 data 都应当视为敏感数据。账本、附件、备份和已保存凭据仍按产品设计加密，
但界面偏好、服务器账号会话等外围状态不保证逐文件加密。

本便携版不扫描、不读取、也不自动迁移旧版本留在 AppData/LocalAppData 的数据。
如需旧账本，请在旧版本中导出 .zcbak，再由便携版手动导入。旧目录不会被自动删除。

“不写 AppData”指应用和 WebView 的持久数据。Windows 自身可能产生 Prefetch、崩溃报告、
Defender、防火墙或最近使用记录，这些系统痕迹不受应用控制。

三、移动、复制和备份

移动、复制、压缩或拔出 U 盘前必须完全退出应用，并等待内置服务器停止。
不要在运行中逐文件复制 data。关闭后移动或压缩最外层完整目录即可保留全部状态。

不要同时运行同一 data 的多个副本。复制出的目录会保留相同设备和服务器身份，
当前版本不支持把克隆副本自动转换为新设备。

data\backups 与账本位于同一介质；磁盘或 U 盘损坏时两者可能同时丢失。
它只算“便携目录内恢复点”，不算独立备份。每次手动、自动或导入前备份会先原子写入
data\backups；若已配置并启用同步服务器，应用随后把同一份加密归档上传到各服务器。
某台服务器上传失败不会删除本机文件，设置页会分别显示本机位置、已成功服务器和错误。

重要数据仍应定期确认至少有一份加密 .zcbak 位于另一块可信介质或健康的远端服务器。
密钥轮换之前创建的旧备份，可能要求输入“创建该备份时的账本加密密码”；该密码只用于
本次校验、演练或恢复，不会保存到备份文件或同步服务器。

执行“重置本机数据”时，应用会连同 WebView IndexedDB 表单草稿、旧账本密钥封套、
Stronghold 凭据、同步配置、自动同步状态、设备身份和临时会话一起清理，避免新账本误用旧身份。data\backups 中已经
落盘的历史归档仍作为单独文件保留；需要恢复时应使用归档创建时对应的账本加密密码。

四、局域网服务器

内置服务器默认监听 0.0.0.0:8787，供可信家庭局域网使用，可能触发 Windows 防火墙提示。
应用不会自行创建或修改防火墙规则。不要把 8787 端口直接暴露到公网；公网部署必须使用
HTTPS 反向代理。端口被其他程序占用或服务器身份文件残缺时，应用会明确报错且不会覆盖。
空服务器默认开放注册；第一位成功完成注册的账号会原子成为管理员，其余账号为普通成员。
管理页面使用管理员账号的正常登录会话，不需要另行保存人工管理密钥。

五、WebView2

Windows 11 使用包内固定版 WebView2。Windows 10 的 NTFS 目录会尝试授予固定版运行所需的
AppContainer 只读权限；失败时回退到系统 Evergreen。Windows 10 + exFAT 直接使用系统
Evergreen；若系统没有可用运行时，应用会提示后退出，不会联网安装。

六、手动升级

1. 退出旧版本并备份整个目录或导出 .zcbak。
2. 解压新版本到临时目录。
3. 只用新版 zichan.exe、portable-mode.json、server、runtime、说明和清单覆盖旧目录。
4. 绝不能覆盖或删除旧目录中的 data。

可用 PowerShell 校验下载文件：

  Get-FileHash -Algorithm SHA256 .\资产生命周期_0.2.0_windows-x64_portable.zip

结果应与同目录 .zip.sha256 文件的第一列完全一致。
