# 离线应用资源与更新

生产 Web 构建生成 `sw.js`，以完整静态资源内容摘要区分版本。首次联网加载后，浏览器安装整个版本的 HTML、JavaScript、CSS、WASM 和其他构建资产；任何必需资源下载失败，该版本不激活。开发服务器和 Tauri 原生壳不注册 Service Worker。

缓存只保存构建时确定的公共静态资源。`/api/`、`/admin/` 请求及附件、用户导出文件不进入 Cache Storage，不缓存账号验证结果或托管凭据。账本缓存及离线授权仍遵循账号隔离与解锁规则。

安装成功且用户曾用账号密码登录并打开账本后，完全断网新开网页可用同一账号密码解锁已有账本。记住设备七天可免输密码。首次注册、首次登录以及没有事先缓存资源的浏览器仍需联网。用户清除网站存储会同时失去离线资源和本机账本副本。

更新下载完成后显示提示，用户保存操作、关闭本站全部旧页面后，浏览器才启用新版。不会强制刷新正在填写的表单，不让旧页面与新资源混用；激活后只清理同一部署路径的旧静态缓存，不清除数据库、密钥或其他网站缓存。

`offline-cache.spec.mjs` 验证真实离线关闭页面再新开、解锁和重新联网，以及 Cache Storage 不含 API URL；`offline-update.spec.mjs` 验证 `/ledger/app/` 子路径、多个旧页面等待更新、激活后保留原账号与记账记录。
