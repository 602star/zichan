## 验收中修复

1. 79 MB Web 目录超过旧自更新协议上限：采用公共资源 gzip 旁车，保持 v1、500 文件和 64 MiB 限制，而非直接放宽旧更新器。
2. 320px 附件网格溢出、草稿恢复未跟随新默认账户：修复布局及未手选值的默认刷新，保留用户明确选择。
3. Linux OCR 输出 `29.90CNY`、日期时间粘连：接受明确币种后缀和日期时间边界；金额缺失时排除邻近日期，不能把 `2026` 当金额。
4. 原生解锁 gate 在启动完成事件前被卸载：原生页面交接前落盘密码加密的离线授权，并用实际便携 EXE 验证。
5. 回归用例区分后台加密备份与 V2 附件上传，断点续传核对具体同步端点；管理预览使用实际安全入口。保留原有上传／续传／权限断言。
6. Linux 字体下后台输入框的固有最小宽度撑破 390px 页面：表单轨道和输入框允许收缩，最终 Linux 页面宽度与视口均为 390px，无越界元素。
