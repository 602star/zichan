# 节点后台复制：网页路由与本机压力验收

已组网账本的 `/api/v3/replica` 返回 `serverManagedReplication`。服务器只要保留复制链路或副本组成员记录，即使链路暂停、授权撤销或副本尚未 `READY`，该字段仍为真。网页发现这一状态后，只向一台节点同步提交与附件；该节点故障时尝试下一台已配置节点。网页记住此账本已采用节点后台复制，不会因临时健康状态下降重新充当节点间的搬运方。尚未进入后台复制的旧多服务器账本仍沿用迁移期兼容路径。

2026-10-11 在一台电脑上运行 `ZICHAN_REPLICA_STRESS=1` 的 `large-three-node-replica.test.ts`：三个独立本机节点共写入 1000 个 V2 加密附件，其中一个附件超过 5 MiB、分成多个加密块；测试模拟中继停服、接收端已有部分分块、复制中途重启。后台复制三轮后，各节点对象数均为 1000，目录差异和链路错误均清零；完整测试约 101 秒。这个时间是本机测试环境的结果，不能作为公网或局域网的吞吐量承诺。

相关回归：`node-replica-routing.test.ts`、`sync-orchestrator.test.ts` 共 15 项及 `node-identity.test.ts` 6 项通过；全工作区类型检查和服务器与网页构建通过。真实公网、家庭和办公室设备仍需独立验收。
