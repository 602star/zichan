- 开发、CI 与发行包内置 Node.js 对齐到 26.13.0 LTS；同步服务镜像也改用 Node 26。更新 TypeScript 6、Vite、Vitest、ESLint、Playwright 等开发工具链，并修复 `systeminformation` 的受影响版本。
- 更新 Web 图标依赖 `lucide-react`、`simple-icons` 和浏览器 SQLite 引擎 `sql.js`；补齐 Web 工作区测试所需的 Vitest 直接依赖，并验证账本快照提交后可重新打开及继续写入。
- 调整窄屏资产预设卡片与图表金额行高，避免 Linux Chromium 字体渲染时出现中文断行或金额截底。
- 修复 Linux/Windows 普通桌面构建在未配置客户端 updater 验签密钥时启动失败的问题；有签名更新配置的构建继续注册 updater。补齐 Rust 格式检查。
- 服务端同步轮次报告接受客户端实际生成的 26 位轮次 ID，并保留原有 UUID 格式，避免后台重复提交返回 400。
- 同站 Cookie 刷新请求在页面重载时继续完成，避免服务端已轮换凭据、浏览器却丢失新 Cookie 后被要求重新登录。
- 加快大量附件对象的测试准备，并延长跨服务器浏览器用例等待主界面的时间，降低 CI 环境中的误报。
- 分类浮层在靠近屏幕底部向上展开时固定底边，内容变化期间保持在视口内。

# 0.1.0

- 新增账号主动改密、自助设备撤销和唯一 Owner 本机限时恢复；改密保留账本保护方式并撤销旧会话。
- 新增生产 Web 静态资源离线缓存及等待旧页面关闭的更新流程；账号登录后自动准备使用同一密码的离线访问。
- 改善手机窄屏表单；密码计算库按需加载，并减少转换重算时对已平仓批次的重复扫描。当时的验收范围与性能数据见[发布准备记录](acceptance/release-readiness.md)。
- Web 采用账号入口，按服务器与账号隔离本机缓存；桌面保留本地和服务器模式。服务器托管账号注册后自动解锁。
- 同步全面改为账号制 OPAQUE 注册与登录。服务器所有者由部署者在独立 `/admin/` 页面显式创建，普通注册不会取得管理员权限。
- 管理界面位于独立 `/admin/`，使用与记账入口隔离的 Cookie；管理 API 位于 `/api/admin/*`，实时校验 Owner/Admin/Member 权限。
- 新增服务器同步组：管理员在主节点创建组，其他节点加入；个人账本在组内自动建立加密副本，同一记账账号和密码可在获准节点登录，各节点保存本地会话与离线缓存。
- 同步地址改为单一规范化完整 URL，并提供“当前网站 / 本机 / 局域网 / 公网”向导及可折叠高级拆分字段；同一服务器的备用地址按 `serverId` 与 OPAQUE 公钥合并，主地址不可用时经身份复核后自动切换并记住可用地址。
- 收紧 HTTP 私网判断：只允许 loopback、RFC1918、IPv4 link-local、IPv6 ULA 与 IPv6 link-local 字面量，普通公网域名即使以 `fc`/`fd` 开头也必须使用 HTTPS。
- 所有凭据发送前都会先匿名核对服务器身份和公钥固定值；连接链接与二维码只携带 URL、`serverId` 和公钥指纹，不包含密码或会话秘密。
- 自建服务器允许任意 Web Origin 以支持官方 Web 连接，但不使用认证 Cookie；OPAQUE、Bearer 会话、设备撤销、角色、持久限流和配额继续承担访问控制。
- 服务器模式允许使用非持久浏览器缓存，默认开启自动同步，并在账本写入后触发防抖增量同步；获准节点使用同一记账账号密码登录。
- 当前按全新部署交付：客户端从空库建立 schema 127，服务器从空数据目录建立 schema 27；旧开发账本、账号、附件、浏览器缓存和同步配置不提供迁移。多节点同步须先由管理员建立同步组。
- 新增加密本地存储、流式备份、附件复制与恢复演练，以及真实银行对账、冻结退款报表、持久化聚合撤销和冲突隔离。
- 新增系统分类包、信用卡与贷款账户，以及股票、基金、债券和贵金属资产。
- 新增 Windows x64 完全便携 ZIP：账本、附件、凭据、WebView 状态、备份及内置同步服务器统一随 `data/` 目录移动。
- 固定并校验内置 WebView2 Fixed Version Runtime；Windows 10 无法设置固定版 ACL 时回退系统 Evergreen。
- 修复 Windows 扩展 `\\?\` 路径下的便携数据库初始化和内置同步服务器启动，并在报告启动成功前校验服务器就绪状态。
- 修复便携 WebView 的 `sql.js` WebAssembly CSP；无需开放 JavaScript `unsafe-eval`，初始化诊断可选择并复制。
- 便携备份改用 Windows 原生“另存为”创建经过校验的独立 `.zcbak` 副本，不再依赖 WebView Blob 下载或分享。
- MSI/NSIS、桌面自动更新、签名 Secrets、GitHub 发布和长期数据库迁移基线统一推迟至 1.0。
