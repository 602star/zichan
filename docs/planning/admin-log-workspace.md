# 后台工作区归并与日志补全

本轮针对日志字段缺失和重复入口统一实施：先确定页面归属、记录契约和验收矩阵，再一次性实现共享查询、筛选、详情与导出。以现有 SQLite 和前端设计系统为基础，不新增第二套后台。

## 唯一页面归属

| 工作区 | 唯一职责 | 合并与兼容 |
|---|---|---|
| 运行概览 | 当前异常与跨模块摘要，链接到明细 | 不再重复完整请求分析和资源维护 |
| 请求分析 | HTTP 路由、5xx、延迟直方图 | 归并监控中心中的请求分析 |
| 访问分析 | PV、UV、会话、地区、页面 | 归并监控中心的访问统计副本 |
| 运行监控 | Node 与当前主机/容器资源趋势 | 数据库、访问、请求、指标目录分别进入各自主入口 |
| 数据库 | SQLite 参数、容量、备份证据及维护入口 | 原 resources、monitor service 的数据库内容指向此页 |
| 采集任务 | 采集器健康、失败、积压 | 不重复维护任务执行列表 |
| 任务中心 | 创建、取消、重试维护任务和进度 | 任务日志只负责检索执行证据，不重做任务操作 |
| 日志管理 | 一个页面外壳，六种记录模式 | 侧栏只保留一个主入口，分类通过页内导航切换；旧六类 URL 继续有效 |
| 告警中心 | 活动/历史、规则入口与投递证据 | 保留一个中心，不另设告警历史主入口 |

用户、会话、邀请、同步、存储备份、账号安全和设置继续沿用现有页面与权限。登录日志中的安全汇总与逐条认证记录放在同一页，删除重复页头和分类导航。

## 日志字段与验收矩阵

| 模式 | 必须可见的列表字段 | 服务端筛选 | 详情与关联 |
|---|---|---|---|
| 系统 | 时间、级别、组件、消息、Request ID | 级别、组件、关键字、请求、时间 | 来源/实例、堆栈、脱敏 JSON、同请求记录 |
| 访问 | 时间、方法、路由、状态码、耗时、IP、Request ID | 方法、路由、状态、IP、耗时、请求、时间 | 采样说明、请求来源、用户代理、系统日志关联 |
| 登录 | 时间、账号、结果、IP、方式、设备 | 结果、账号、IP、方式、事件、请求、时间 | 失败原因、第二因子、用户代理、来源与 Request ID；安全汇总 |
| 操作 | 时间、操作者/角色、对象、动作、结果、IP | 操作者、动作、对象、结果、IP、请求、时间 | before/after 脱敏摘要、原因、成功与失败一致检索 |
| 任务 | 任务名/ID、开始、结束、状态、耗时、尝试、实例 | 任务、状态、实例、请求、时间 | 错误码、阶段、进度、运行事件、重试关系、任务中心链接 |
| 容器 | 时间、容器、stdout/stderr、内容 | 容器、流、关键字、时间 | 原文、有限下载、跟随/暂停；宿主机白名单只读桥接，未配置明确说明 |

## 共用约束

每类使用同一时间组件、URL 筛选状态、游标分页、页长、追踪/暂停、刷新/重试、采样来源与状态，以及带焦点边界的详情抽屉。导出遵循同一筛选契约，按类型返回不同表头，限制最多 5,000 条并提示截断，脱敏且防 CSV 公式注入，写入导出审计。旧数据缺字段显示未记录，不能推测为成功、0ms 或当前实例。

后台不访问 Docker Socket。宿主机只读导出白名单容器日志为有界状态文件，后台只读固定文件，不接受任意路径或命令。认证记录独立持久化，不受普通系统日志条数清理影响；请求上下文由服务端产生。

## 实施与验证

依次完成统一日志数据查询与生产端上下文、分类字段配置与共用页面、旧路由与重复内容归并、导出和故障/空状态，再集中验证。测试覆盖真实产生的认证与管理操作、组合筛选、成功/失败区别、重试次数、游标边界、导出表头/注入、敏感信息、未配置与已配置容器来源、桌面/手机和键盘返回。完成后更新本清单、现行手册和工作日志，旧实现与不再使用的样式同时移除。
