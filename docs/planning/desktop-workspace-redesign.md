# 电脑端账本工作台结构方案

导航收敛（2026-11-15）：电脑侧栏不再显示“资产”聚合入口，直接使用账户、资产转换、物品资产等任务；手机保留固定“资产”入口。下文资产聚合设计与预览记录保留作背景，现行导航以操作指南为准。

状态：2026-11-15 用户确认设计后，已将桌面任务结构迁移到实际前端。流水采用通栏与行内展开；新增在顶部连续录入，复杂编辑进入主内容区。实际操作见[电脑端账本工作台](../guides/desktop-ledger.md)。下文保留结构依据及设计候选；预览覆盖表用于追溯设计，不代替实际功能和验收记录。

本轮落地包括分组及可收起侧栏、独立账户与计划入口、定投登记买入、查询往返、工作台任务与最近流水、资产与物品清单、游戏详情、转换主区编辑、历史整页详情、资料／设置／账号局部目录及宽屏报表。通用控件、数据库服务、金额计算和手机导航继续共用。流水的独立记录页、方向键切换及可排序物品列保留为后续增强；本轮选择已确认的行内展开作为流水详情方式。

## 目标与依据

面向需要连续处理多笔记录的个人用户，将电脑端组织为以通栏流水为主的账本工作台，详情在记录下方展开或进入独立记录页。沿用“大福帳 · 墨与朱”、三种纸张、明暗模式及现有卡片词汇；手机保留已完成的导航与交互，共享账本逻辑、字段规则、校验和计算。

依据为当前源代码和最近一轮 1280px 实际页面截图：

- 侧栏固定 260px，全部模块开启时 11 项同级排列；账户位于收支页内，资产入口又包含账户、持仓和物品，任务入口需要明确主次。
- 流水截图中新手引导展开时，首条记录落到 900px 首屏之外；今日／本周、月度摘要、视图、期间、搜索与筛选分别占据纵向空间，记录行又被多项常显操作撑高。
- 资料管理同时有主标签、分类模式及其他资料标签，层级不易辨认。
- 转换页把资产摘要、买卖入口、历史和展开后的步骤明细放在同一条纵向路径；报表把走势、构成、汇总表、流水明细和分析继续往下堆叠。
- 历史页已有列表与侧边详情，可作为统一主从结构的起点。

截图包含隔离测试账本与新手状态，用于检验结构和极端数据长度，不代表个人真实财务情况。后续原型也必须标明示例数据。

## 信息架构

| 层级 | 入口 | 职责 |
| --- | --- | --- |
| 日常 | 工作台 | 待处理事项、最近流水、继续上次核对；简短收支摘要 |
| 日常 | 流水 | 搜索、筛选、查看、编辑、退款、批量整理及连续录入 |
| 日常 | 账户 | 账户列表、原币余额、账户流水、余额核对 |
| 日常 | 计划 | 预算、账单和定投计划，各有明确局部导航 |
| 资产 | 资产 | 持仓、转换记录、物品、游戏；按既有模块显隐展开 |
| 分析 | 报表 | 收支、定投、转换、物品、游戏的统一分析入口 |
| 底部工具 | 资料／操作历史／设置 | 资料维护、审计追溯、设备同步备份恢复；个人账号单独入口 |

“账户”统一表示资金账户，“我的账号”表示服务器身份。资产页中的账户或计划页中的账单等关联入口，指向同一任务页并带入上下文，不复制业务页面。侧栏保留用户的模块偏好；旧 screen／tab 定位映射到新入口，不能因改名丢失原入口。

## 页面骨架

全局顶栏保留账本位置、报表币种、账本日和真实保存／同步状态；新增入口明确区分记账与其他记录。使用约 200–220px 的可收拢侧栏，将有效宽度留给正文。每页固定顺序为标题与主动作、紧凑摘要、查询工具、主要内容。

流水始终占用完整正文宽度，不设置右侧常驻详情或详情抽屉。“行内展开”在所选记录下方呈现附加信息、凭证和操作；“独立详情”在正文打开记录页，提供上一笔、下一笔及返回列表，保留筛选和返回位置。1024px 窗口优先收拢导航，1280／1440／1920px 分别验证表格列与编辑宽度。

| 页面类型 | 主区 | 辅区 | 适用页面 |
| --- | --- | --- | --- |
| 记录工作区 | 可排序、筛选和勾选的通栏列表／表格 | 行内详情或独立记录页；新增使用顶部快记区 | 流水、账户流水、历史、资料、物品、游戏记录 |
| 交易编辑页 | 按任务分组的完整表单或连续步骤 | 同列分组的实扣、到账、手续费、成本与缺价摘要 | 连续转换、复杂记录、计划编辑 |
| 分析页 | 统一期间与口径、核心结果、并排图表 | 当前分类或时间点的明细 | 报表、资产／赛季分析 |
| 设置页 | 单个设置任务的内容 | 窄幅局部目录 | 设置、账号、同步与恢复 |

## 流水与连续录入

流水是第一批样板页。标题行提供新增；摘要保留当前范围收入、支出、结余和条数，说明退款及缺价口径。搜索、期间及已应用筛选集中在记录上方，额外条件按需展开。今日、本周成为期间快捷项；趋势和分类分析进入报表关联入口，任务页保留紧凑结果。

表格默认突出日期、摘要、分类、账户和原币金额。状态用真实文字或徽章，低频操作集中到一处；金额保留币种与完整精度，不能用省略号掩盖数值。每日墨线和小计保留，表头吸顶；勾选后出现批量工具条。普通密度行高约 40–48px，允许较大字号和长内容自然增高。

桌面点行就地展开，或进入独立记录页；明确点击编辑后在主内容区编辑。该变化替换当前桌面点行直接编辑，必须保留可见编辑按钮和键盘路径。切换记录、收起录入或离开页面时，未保存修改沿用草稿保护。

新增候选采用表格上方的横向快记区；独立记录页方案也提供独立编辑。核心字段保持固定次序，提供“保存”与“保存并继续”；后者成功后清空金额和描述、回焦金额，日期／账户／分类的保留规则明确可选。保存失败保留全部输入并定位错误。新记录若被当前筛选排除，提示原因并提供查看入口，不擅自重置筛选。

建议快捷操作为 Ctrl／Cmd+Enter 保存并继续、Esc 退出当前层、方向键选择记录、Enter 查看；具体按键需检查浏览器、输入法及现有快捷键冲突，文本输入时不劫持单字母键。

新手引导第一次使用时帮助完成首笔记录；已有记录后收为可重新打开的任务提示，不持续压在流水上方。首次使用、加载、空列表、无匹配结果、读取失败、保存中、同步异常和超长金额均作为独立状态设计。

## 账户核对

账户选择、余额与实际余额核对位于流水上方，核对结果在余额输入附近展开，下方保持通栏账户流水。展示逐币种的期初、流入、流出和期末；用户填写实际余额后，按现有流程明确显示差额、影响和确认动作，保留操作历史。原币余额与折算现值分开，不将多种币的原始数量合计成一个金额。

从账户进入流水时携带账户与期间；返回保留选中账户、筛选、行位置和滚动位置。报表期间、当前筛选和账户余额截至时间分别说明，不能共用一个看似全局、实际作用范围不同的日期控件。

## 其他页面的分工

- 工作台：优先展示待处理账单、待核对事项、缺价和最近记录；资产概况用紧凑摘要表达。详细趋势留给报表，避免首页重复整套分析。
- 资产：持仓以可比较的表格为主，选资产后查看余额、成本、批次及关联记录；持仓快照与交易历史的日期作用域分开。
- 转换：资产列表和交易历史分开浏览，复杂新增／编辑进入独立交易编辑页。核对摘要随表单变化，缺价和未知成本明确显示，不用当前行情偷偷补历史成本。
- 物品：桌面默认可排序的物品清单，适合比较成本、残值和单位使用成本；可选图片视图。选中物品后复用概况／使用／事件组织。
- 游戏：赛季选择、投入回收摘要和记录列表；详情保留游戏币数量、结算与折算的区别，缺价不显示为零。
- 报表：顶部一处期间和口径，走势与构成在宽度允许时并排；点击图表联动下方明细，整理流水时带着筛选跳转。只有一个数据点时避免用大块图形占满屏幕。
- 预算／账单／定投：同属计划入口，分别按目标、到期执行、投资安排组织；不在一个表格混合计算不同业务口径。
- 资料：局部竖向目录替换多层横向标签，右侧显示当前资料表；分类树、条目和编辑详情逐层展开。
- 历史：保留列表与差异详情，统一列与详情行为；撤销仍明确影响范围。
- 设置／账号／同步恢复：一个任务对应一个内容区。正常同步状态简短可查，失败给出具体恢复操作；备份演练、恢复及安全确认继续使用原有保护流程。

## 实现边界与顺序

1. 先验证流水工作区：完整普通／选中／编辑／连续新增／批量／空态，另验从账户核对跳入流水的往返。
2. 确认候选后提取桌面骨架：AppShell、PageToolbar、SummaryBand、RecordWorkspace、RecordExpansion／RecordDocument、QuickEntry。通用字段和业务表单复用现有实现，外层容器按平台选择。
3. 迁移账户与核对、资料、历史、物品、游戏；保留服务和计算接口。
4. 迁移转换编辑、计划、报表及工作台，再统一设置和账号局部导航。
5. 补跨页状态、键盘、焦点、加载与错误状态，回归手机布局和手势。

拆分 Transactions 时按流水、账户、预算、账单及编辑容器拆分职责，避免只把现有大组件套进新布局。路由承载页面、账户、选中记录和可分享查询；滚动位置、密度、列偏好等临时视图状态独立保存。跨页定位继续兼容既有 screen-target。

## 验收目标

- 以已有记录、引导收起的典型测试账本验证：1280×800 首屏能操作搜索与新增并看到至少 8 条普通流水；长文本、最大精度金额、大字体另测，不为了条数裁剪信息。
- 查看、编辑下一条和保存并继续时，不丢筛选、选中状态、滚动与草稿；排序及分页不使核对小计变化口径。
- 汇总与每日／账户统计使用完整查询聚合，不以屏幕已加载行代替。退款、转账、多币种和缺价遵守既有计算规则。
- 1024／1280／1440／1920px 无页面横向溢出；表格确需横滚时只在数据区发生。展开详情不缩窄金额列；独立详情返回后保留查询及位置。
- 三纸张、浅深色、键盘全流程和浏览器缩放检查；手机原有流程与 Android 共用表单不回退。
- 同时核对真实状态：本机已写入、草稿已保存、等待同步、同步失败与服务器副本完成分别表达。
