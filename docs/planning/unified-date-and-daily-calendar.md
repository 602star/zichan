# 统一时间选择与日常日历方案

状态：2026-11-16 已实施快捷范围与共用日期面板。用户随后明确将完整日历放在首页，已据此增加农历／节假日显示、首页日历、日程提醒、公历／农历生日、纪念日和可关联流水的随记；现行操作及通知、历法范围和导入边界见[首页日历](../guides/home-calendar.md)。下文保留初始方案依据，入口以首页实现为准；自定义区间草稿／成对确认仍未实施，表单日期沿用 DateTimeInput。时间筛选操作见[Web 说明](../guides/web.md#统一日期浏览)与[后台说明](../guides/server-admin.md#日常使用路径)。

## 设计结论

保留前台 `DateRangeBar` 的结构和快捷范围下拉，将“从／至”两个日期字段打开的面板统一为后台 `CalendarDatePicker` 的年月日导航。提取共用日历底层，让日期选择、区间选择和账单月历共用日期计算、农历及节假日信息，分别保留各自任务需要的交互。

用户端在流水页强化现有“月历”视图：上方看每日收支分布，下方看选中日的流水、到期提醒与随记。沿用文献纸、文楷、墨线、收入藍、支出赤和朱色操作；电脑端使用通栏日历与下方明细，不新增常驻右侧详情栏。手机保持现有底部导航及记一笔入口。

## 时间选择控件

### 布局

保持用户指定的结构：`[本月 ▼] 从 [2026/11/01 日历] 至 [2026/11/30 日历] [清除]`。

- 快捷下拉常驻；电脑端从／至并列。手机允许日期对换行，不能缩小到难以点选，也不能只剩无标签图标。
- 前台保留今天、本周、本月、上月、近 3 月、今年、全部时间、自定义；“近 3 月”沿用当前包含本月的三个自然月，避免改变已有统计语义。
- 后台按任务提供近 1 小时、近 24 小时、近 7 天、近 30 天、自定义等现有可用项，遵守各页上限；不把前台自然月与后台滚动小时窗口混成同一含义。
- 日期字段显示公历，点击打开统一年月日面板；可用年／月导航快速跳转，不用连续翻几十个月。鼠标用户保留格式明确的键盘输入路径。
- 范围面板显示起点、终点及区间浅底；当前编辑端点要有文字标识。桌面可双月并排，手机单月。单日表单不出现区间操作。
- 面板内编辑为草稿，选好后“应用区间”一次提交，取消或 Escape 丢弃；不要让用户刚选完起点就查询一次。
- 前台快捷范围选择立即生效；自定义起止成对应用。后台自定义继续使用外层“应用”，内部选日只更新草稿，避免两层应用按钮；后台快捷范围保持既有即时应用行为。
- 清除仅取消时间筛选；不清除账户、分类、搜索词或视图偏好。必填表单日期不得出现可清空操作。
- 起点晚于终点时保留草稿，明确提示并禁用应用，不再静默挪动另一端。保持各页面已有的单边范围能力。

### 日期与时刻

- 账本业务日仍保存 `YYYY-MM-DD`；范围两端在业务日层面均包含，不因农历展示转换存储日期。
- 操作历史和后台诊断属于时间戳查询。用户显示的本地时刻转 UTC 传输，清楚显示生效时区；不要拿 UTC 字符串前十位当本地日期。
- 将业务日转换为瞬时时间范围时，使用该业务场景的时区与“次日零点”结束边界，避免硬加 24 小时导致夏令时错位；后台现有 `until` 是否包含由对应 API 契约决定，不能只换控件就改变端点语义。
- “今天”按钮在账本内按账本时区与账本日计算；后台、操作历史仍按对应查询的显示时区计算，避免所有页面直接套 `localToday()`。
- 后台滚动快捷区间现为 `from` 起、无固定结束值，新记录可继续进入；统一外观时保留并提示“持续更新”，不擅自改成固定截断。

## 农历、节日与放假安排

日期下方一行辅助文字，优先级为重要节日、节气、农历日；完整信息放在选中日期的标题下。角标“休／班”独立于辅助文字，保留公历日期为首要信息。

- 前台中文日历默认显示农历与主要节日，可分别关闭；后台精确查询默认收起辅助信息，可用同一偏好控制。首周一默认沿用当前实现。
- 农历、传统节日和节气属于历法计算，候选为 MIT 的 [lunar-typescript](https://github.com/6tail/lunar-typescript)。正式选型需要验证打包体积、运行环境、闰月与已支持年份，不因库包含其他功能就全部展示。
- 大陆放假调休属于年度数据，候选为 MIT 的 [holiday-cn](https://github.com/NateScarlet/holiday-cn)。它提供 `isOffDay` 与来源公告，明确提醒跨年可能受次年文件影响，且部分与周末连休的日期不在数据中。
- 按已核实年度打包离线数据，并保留来源、地区、版本与覆盖状态。跨年合并相邻年度数据，补班优先于普通周末；缺失年份只显示周末和节日，不臆造“休／班”，显示“该年调休安排未收录”。
- 不在每次打开月历时请求第三方接口；节日标签不改变账单到期日、工作日或自动记账规则。若以后支持按工作日顺延，须作为独立计划功能设计。

## 用户端日历

### 入口与层次

以现有流水页“列表／月历”切换为主入口，年度回顾和单日查看保留为次级能力；首页可提供“查看日历”，进入同一页面并定位今天。第一期不新增手机底部导航项。

内容依次为：期间筛选、月份导航、月格、选中日期标题、该日流水、到期提醒、随记。点击某日只更新下方明细，不自动离开月历；再点某笔流水复用现有查看、编辑、退款入口。

- 电脑月格显示公历、辅助日期、支出／收入两行及记录状态，不塞多笔摘要；金额带明确“收／支”，大数使用可解释的缩写，完整金额在下方。
- 手机月格优先显示日期、辅助日期及一项日净支出或记录标记；完整收支在选中日显示，不能把七列挤成密集小字。
- 当天、选中日与有记录日使用不同表达；休／班有文字，随记使用统一线性图标并有可读标签，不能只依靠颜色。
- 无流水日显示“当天还没有流水”，提供“记一笔”与“写随记”；记一笔预填所选业务日，时间仍按既有表单规则，不凭空制造精确时刻。
- 未来日期可看计划提醒、写随记；未入账计划不计入已发生收支。仅标记账单已处理不增加支出；不从信用卡余额推断应还金额或逾期。

### 月份与筛选

- `visibleMonth`、时间范围和 `selectedDate` 分开建模。切到月历时先显示所选范围内最近的相关月份；“全部时间”默认本月。
- 点选日不改全局时间范围。自定义跨度跨月时，月格保留范围外日期轮廓但不混入范围外汇总；选日限定在范围内，标题明确显示当前期间。
- 主动切换上一月／下一月时，将时间范围同步为目标整月并显示为自定义，保留非日期筛选；从跨月区间进入单月前明确显示新的起止日期，防止月份标题与查询内容脱节。
- 从报表下钻保留分类、账户与期间；返回列表保留这些筛选。日期导航、查询失败重试和编辑后刷新都不得丢失未保存随记。
- 月格聚合、当天明细和范围汇总使用同一筛选及报告归属日规则；退款沿用当前账本归属政策，明细在发生日不同于归属日时同时说明两者。
- 分类或搜索筛选只约束流水及金额；提醒和随记为所选日的其他内容，分别标注“当天提醒”“当天随记”，不会因为金额或分类不匹配而消失。

### 查询完整性

全月金额和笔数从数据库按日期聚合，不能从当前加载的 100 条明细推断。复用 `transactionBrowseAggregate`／报告归属逻辑并补齐需要的完整计数；按日期选择后再调用分页查询。快速切月和切筛选必须取消或丢弃过期结果。

所有金额继续使用 core 的十进制工具与报告币种规则。缺汇率显示“未完整折算”；加载失败、没有记录和真实金额为零分别显示，不把未加载显示成零。至少验证单日超 100 条、月度超 1,000 条及多币种。

## 每日随记

用户确认范围：每天写几句，可关联账单。第一期建议一账本一天一条纯文本随记，可编辑及删除，可关联多笔现有流水；不要求先记账，也不通过零元交易承载文字。

- 选日后显示“写几句今天的事…”，展开编辑与关联流水选择；“保存随记”明确提交，离开、切月或关闭时保护未保存草稿。
- 关联对象第一期指已记录的流水；“关联流水”是明确按钮。到期账单／计划在当天提醒中查看，避免把计划金额与已发生金额混合。
- 随记日期独立于关联流水日期；跨日关联时显示流水实际日期，不自动移动随记。关联流水修改后引用更新；作废或删除的引用显示状态并可移除，不把随记一起删除。
- 单纯记录心情或事项不影响收入、支出、账户余额或预算。月格用一个随记标记，正文只在所选日展开。
- 保存状态区分“已保存在本机”“等待同步”“同步失败”；不能把本地保存说成已同步。多设备同时编辑要复用冲突处理，不能静默覆盖。

建议独立实体 `DailyNote`：账本 ID、日期、正文、关联流水 ID、创建／更新时间、版本、删除状态；一账本一天唯一。字段及关联方式以现有仓储约定实现，需覆盖 SQLite 迁移、实体同步白名单、冲突、加密导出／恢复与删除恢复，不能只写浏览器 localStorage。富文本、多图日记、独立待办、农历周期提醒和系统日历订阅留待后续需求。

## 建议实施顺序与验收

1. 统一控件：先合并前台、后台日期面板和快捷下拉；验证必填、单边、反向、取消、键盘、触屏、时区、UTC 端点和后台持续更新语义。
2. 农历节假日：接可离线的历法与年度数据；验证闰月、春节／除夕、节气交界、跨年调休、补班和未知年份，确认不改变账单日期。
3. 财务月历：独立每日聚合与选日分页，接提醒和按所选日记账；验证筛选往返、退款归属、缺汇率、高记录量、切月竞争、失败重试。
4. 随记：连同迁移、同步、冲突、备份恢复一起实施，验证无流水日、跨日关联、关联作废、编辑保护、离线写入后重连。

正式 UI 验收覆盖 320／390／768／1280px、浅深色、字号放大、键盘和触屏；本机不能验证的内容按仓库约定切 Linux 测试机。此文档与配套交互草案只作设计评审，不代表功能上线或生产测试通过。
