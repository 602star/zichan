## 性能测量

`transaction-scale.mjs`：10k 筛选 P95 6.33 ms，100k 筛选 65.71 ms，100k 半年汇总 212.13 ms，100k 账户余额 121.19 ms，均在脚本原预算内。

`conversion-scale.mjs 2000`：4000 条交替买入/全部卖出的转换，五轮完整重算从 `[593.28,575.72,573.15,578.89,613.63]` ms 降到 `[180.83,166.98,162.2,161.42,161.31]` ms。只从候选持仓中移除已平仓批次，完整历史及派生输出仍保留；147 项 DB 测试通过。仍保留全量重算，没有宣称实现历史后缀增量重放。

OPAQUE 与 Argon2 改为实际认证/解锁时加载，账本共享 JS 从约 888 kB 降到 439 kB，当前构建不再出现大 chunk 警告。离线资源仍预缓存全部必要分块，因此优化的是入口加载与执行依赖，不是减少整个离线包的总大小。
