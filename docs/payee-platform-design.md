# 交易对象与平台目录

日常收支使用一个可选输入框：支出显示「商家 / 平台」，收入显示「付款方」。管理页统一称为「交易对象」。支持直接填写名称，也可搜索个人交易对象或平台目录中的名称、别名。

## 选择与推荐

- 平台目录按外卖与餐饮、商超与生鲜、电商购物、打车与用车、旅行与住宿、电影与演出、会员与数字服务、通信缴费、快递物流九个场景组织。同一个平台可以出现在多个场景。
- 当前分类只影响相关平台推荐。选择平台不改变分类或账户，也不会启用隐藏分类。场景不是二级记账分类，不参与分类预算。
- 最近使用和常用对象从完整账本的有效交易汇总，不受当前流水分页或筛选限制。
- 手机与桌面共用输入控件，场景目录在表单内展开，不改变共享弹窗宽度。

## 数据规则

- 目录是随应用发布的离线建议，不在新账本中批量创建交易对象。
- 保存交易时才创建选中的目录项或自定义名称，与交易处于同一数据库事务；取消和失败不会留下空对象。
- 优先复用已有名称、别名或平台稳定标识。目录项创建后保留规范名及别名，改名后仍可识别；停用或删除后不通过目录重新创建。
- 新对象不自动记录首笔交易的分类、账户为默认值；已有对象的配置予以保留。
- 原有 merchant 文本、payeeId 引用及表单字段偏好兼容保留；旧 merchant 字段偏好映射到统一输入框。

## 范围与维护

本次接入日常收支新增和编辑；模板、计划交易、固定资产中的独立表单未替换输入控件。数据库字段不迁移。

目录维护位置：`apps/web/src/payee-catalog.ts`。新增条目须检查别名冲突、场景与分类映射，避免把某一平台推荐给整类不适用的消费。例如打车与租车、电影与演出分别限制具体推荐范围。

品牌名称核对参考：[美团](https://www.meituan.com/)、[淘宝闪购](https://taobaoshangou.ele.me/)、[携程](https://app.ctrip.com/)。目录仅用于手工记账，不代表账号绑定或自动导入支持。
